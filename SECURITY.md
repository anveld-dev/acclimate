# Security policy

## Supported versions

We provide security fixes for the latest release from `main`.

## Reporting a vulnerability

Open the repository's [GitHub Security Advisories](https://github.com/anveld-dev/acclimate/security/advisories) and select **Report a vulnerability** to open a private report. Keep vulnerability details out of public issues, pull requests and discussions. If the reporting button is missing, ask the maintainers on GitHub for a private reporting channel and leave out the details.

Include the affected version or commit, the components involved, the conditions needed to trigger the issue, and the potential impact. Include minimal steps and redacted evidence that help us reproduce it. If you self-host Acclimate, leave out secrets, including database passwords, machine tokens, OIDC client secrets and model credentials. Use test data in place of private prompts, cases and logs.

We aim to acknowledge reports within seven days. We'll use the private advisory to ask for any additional information, discuss the impact and coordinate a fix and disclosure. Timing depends on the severity and complexity of the issue.
