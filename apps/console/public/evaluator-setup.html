Application evaluator setup

Node.js · Python

Node.js evaluator

Install the SDK release in the application environment. Substitute the path to your release artifact.

npm install --offline --ignore-scripts /absolute/path/to/release/acclimate-sdk-0.2.0.tgz

In the directory where you run your agent, create application.mjs. Replace the imports with your existing agent, independent grader and saved cases. Each case supplies a unique public caseId, private input and private expected.

// application.mjs
import { runAgent, scoreResult, savedCases } from './dist/support-agent.mjs';

export const cases = savedCases;
export const revisionFiles = ['package-lock.json'];

export async function execute({ version, input, signal, context }) {
  const result = await runAgent({ version, task: input, signal, job: context });
  return { output: result.answer, usage: result.measuredUsage };
}

export async function grade({ output, expected }) {
  return scoreResult(output, expected); // { reward, explanation? }
}

Run npx --no-install acclimate-eval describe from that directory. Give its public JSON to the person creating the console request. Keep case contents and credentials on the evaluator machine.

Ask the service operator for a workspace read/write evaluator principal and its private JSON configuration. Save the downloaded handoff as handoff.json in the application directory. Use the physical absolute path from realpath /path/to/evaluator.json and the physical path for journalRoot. Keep the config file at mode 0600 and its enclosing directory at 0700. On macOS, /var points to /private/var.

npx --no-install acclimate-eval doctor --config /private/evaluator.json --handoff handoff.json
npx --no-install acclimate-eval compare --config /private/evaluator.json --handoff handoff.json --policy /private/quality-policy.json --live

--live runs your agent and grader for both versions. Supplying a policy reports its verdict to the console. Omit --policy to collect comparison evidence alone.

Python evaluator

Install the SDK release in the application environment. Substitute the path to your release artifact.

python3.11 -m pip install --no-index --no-deps /absolute/path/to/release/acclimate_sdk-0.2.0-py3-none-any.whl

In the directory where you run your agent, create application.py. Replace the imports with your existing agent, independent grader and saved cases. Each case supplies a unique public caseId, private input and private expected.

# application.py
from acclimate.evaluation import ExecutionResult, GradeResult
from support_agent import run_agent, score_result, saved_cases

cases = saved_cases
revision_files = ["support_agent.py", "requirements.lock"]

async def execute(run):
    result = await run_agent(version=run.version, task=run.input, cancellation=run.cancellation)
    return ExecutionResult(output=result.answer, usage=result.measured_usage)

def grade(run):
    verdict = score_result(run.output, run.expected)
    return GradeResult(reward=verdict.reward, explanation=verdict.explanation)

Run python -m acclimate describe from that directory. Give its public JSON to the person creating the console request. Keep case contents and credentials on the evaluator machine.

Ask the service operator for a workspace read/write evaluator principal and its private JSON configuration. Save the downloaded handoff as handoff.json in the application directory. Use the physical absolute path from realpath /path/to/evaluator.json and the physical path for journalRoot. Keep the config file at mode 0600 and its enclosing directory at 0700. On macOS, /var points to /private/var.

python -m acclimate doctor --config /private/evaluator.json --handoff handoff.json
python -m acclimate compare --config /private/evaluator.json --handoff handoff.json --policy /private/quality-policy.json --live

--live runs your agent and grader for both versions. Supplying a policy reports its verdict to the console. Omit --policy to collect comparison evidence alone.
