title: Glossary
description: Definitions of the terms these docs use for delivery, for the learning loop and for people and access.
---

This page defines each term in one line. [How Acclimate works](/docs/concepts/how-it-works) shows how they fit together.

## Delivery

| Term | Meaning |
| --- | --- |
| Workspace | The scope for bundles, connections and their members. |
| Bundle | A named collection of agent instructions, skills and memory files. |
| Version | An immutable snapshot of a bundle. |
| Payload | The document that holds a version's files. |
| Digest | A hash of a version's exact bytes, which the SDK checks every download against. |
| Channel | A named reference, such as `stable`, to the version jobs should use. |
| Release | A move of a channel to a version, with a reason. A rollback is a new release. |
| Current version | The version a channel points at now. In a round, the API reports its score as `incumbentScore`. |
| Connection | The link between an application and the bundle and channel it uses. |
| Job | One run of your agent, which keeps the version it prepared at its start. |
| Receipt | An optional report of which version a job started with. |
| Plugin | A package, such as `@acclimate/codex-plugin`, that prepares a version's files for one agent SDK. |

## Learning

| Term | Meaning |
| --- | --- |
| Learning loop | The service process that improves one bundle on one channel, round by round. |
| Round | One pass of the loop. See [What a round does](/docs/concepts/how-it-works#what-a-round-does). |
| Daily round limit | The most rounds a loop runs in a rolling 24 hours. It defaults to 4. |
| Task | One learning example: an input with an expected answer or grading criteria. It is a row before import. |
| Split | The evolve or held-out set a task belongs to. It never changes. |
| Evolve split | The tasks the loop learns from. |
| Held-out split | The tasks that only measure a released version. They never reach the optimizer. |
| Source group | Tasks that always share a split: those from one source row or with the same input, even across imports. Each production outcome is its own group. |
| Admission | The check a task passes before it counts. A task that fails is set aside with a reason. |
| Outcome | A production job's input and the answer it should have given, reported by the application. It becomes a task. |
| Rollout | One run of one task against one version, in a fresh sandbox. |
| Trial | One **Try task** run from the console. It does not count toward scores. |
| Executor | The process that runs rollouts and trials in sandboxes and grades them. |
| Runner image | The container image each sandbox runs. |
| Gateway | The executor's proxy to the model provider, the only way out of a sandbox. |
| Model provider | The OpenAI-compatible endpoint, provider API key and allowed models saved for a workspace. |
| Task model | The model that answers tasks. |
| Judge model | A different model that grades answers against criteria and converts imported rows into tasks. |
| Optimizer | The model, set on the service, that proposes, screens and selects changes to a bundle. |
| Candidate | One of the five changes proposed in a round. |
| Adoption | A round's decision to release a candidate in place of the current version. |
| Improvement memory | The optimizer's record of problems, attempts and results. It is never delivered to jobs. |

## People and access

[Credentials and rights](/docs/concepts/credentials) says what each credential can do.

| Term | Meaning |
| --- | --- |
| Operator | The person who runs the service, creates workspaces and sets the optimizer. |
| Workspace administrator | A member with the Administrator role, who manages members, connections, credentials and the model provider. |
| Connection credential | A secret that reads the released version for one connection. |
| Receipt credential | A secret that reports which version a job started with, for one connection. |
| Machine token | A credential for scripts and CI, with the rights you tick: read, write or promote. |
| Executor credential | The secret that lets an executor take learning work from the service. |
