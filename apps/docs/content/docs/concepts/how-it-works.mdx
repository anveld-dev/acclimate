---
title: How Acclimate works
description: Follow one change to your agent's instructions from an edit to a graded comparison, a release, and delivery to new jobs.
---

Acclimate manages the instructions, skills, and approved memory your app gives an agent. You set up the starting files and the tests once. The app reports corrections, and Acclimate uses them to propose and test changes. [Glossary](/docs/concepts/glossary)

## Save content as versions

A **bundle** holds the files one agent uses: instructions, skills, and approved memory. Each **version** is an immutable snapshot of those files, identified by the SHA-256 digest of its exact bytes. A **channel** such as `stable` points at the version new jobs should use.

## Compare a change

Saving an edit creates a **candidate** version that records its **parent**, the version it started from. An **evaluator** in your environment runs your agent on both versions, using the same saved **cases** and the same grader, and reports the scores. The evaluator is the SDK's CLI plus an application module you write: it exports your cases, a function that calls your agent, and a function that grades the output. Acclimate never runs your agent or sees your model credentials.

The **comparison** records which versions ran and the paired scores. You can apply a **policy**, your written release thresholds, to get a pass, fail, or indeterminate verdict.

## Review and release

Acclimate runs the connection’s release checks, including an independent audit. Passing changes advance the delivery revision automatically. A failed or incomplete check keeps the current version in service. You can inspect the scores, candidate, and decision for each round.

## Deliver content to jobs

When your application starts a job, the SDK resolves the channel, downloads the version, verifies its digest, and prepares the files for your agent. Save the version ID with the job's result. A release changes what new jobs receive. Jobs already running keep the content they started with.

A **connection** ties an application to its workspace, bundle, and channel. If you enable [connected learning](/docs/guides/connected-learning), your application can report **outcomes** and approved corrections, and the service can propose changes and schedule comparisons for your evaluator.

## Responsibilities

| Component | Responsibility |
| --- | --- |
| Acclimate service | Stores workspaces, versions, comparisons, and releases, and enforces who can read or change them. |
| Acclimate SDK | Resolves, verifies, and caches versions, prepares files for a job, and runs comparisons as the evaluator CLI. |
| Native plugin | Maps bundle files to the files or options a particular agent SDK expects. |
| Your application | Runs the agent, owns model and tool access, private task data, and grading. |
