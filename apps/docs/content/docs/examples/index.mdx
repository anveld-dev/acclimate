The repository's [`examples/`](https://github.com/anveld-dev/acclimate/tree/main/examples) directory holds small programs you can run against your own service. Two of them have a walkthrough here.

| Example | What you do | Walkthrough |
| --- | --- | --- |
| `examples/support-agent/` | Answer a support request with the released bundle, improve the bundle with 60 sample tasks, and report a person's correction as a new task. TypeScript and Python. | [Support agent](/docs/examples/support-agent) |
| `examples/ticket-triage/` | Publish a bundle, import 64 labelled tickets, start the learning loop and follow each round from one script. TypeScript and Python. | [Ticket triage](/docs/examples/ticket-triage) |
| `examples/learning/` | Import 60 ready support tasks, each with its own grading criteria. | [Support agent](/docs/examples/support-agent#improve-the-bundle-with-the-sample-tasks) |
| `examples/delivery-check.ts`, `python/examples/delivery_check.py` | Prepare the released version for a connection and read back the verified files. | [Try Acclimate on your laptop](/docs/get-started/quickstart#connect-your-application) |
| `examples/claude-agent.ts`, `codex-agent.ts`, `cursor-agent.ts` | Run a coding agent on the prepared files. | [Claude Agent SDK](/docs/integrations/claude-agent-sdk), [Codex](/docs/integrations/codex), [Cursor](/docs/integrations/cursor) |
| `examples/native-repository/` | Stage an existing repository for a coding agent, with an offline replay harness. | [Deliver content to jobs](/docs/guides/deliver-content#prepare-an-existing-repository) |

## Set up once

Both walkthroughs use the local stack and a source checkout. They also work against any Acclimate service if you set the same variables.

1. Start the [local stack](/docs/get-started/run-locally) with a [local model proxy](/docs/get-started/run-locally#local-model-proxy), so that the service has an optimizer model and the workspace has a verified model provider. The support agent's first step works without either.

2. Load the stack's client settings in the shell you run the examples from. The file sets `ACCLIMATE_URL` and `ACCLIMATE_WORKSPACE`, and makes Node.js and Python trust the stack's certificate.

   ```sh
   source .local/stack/env.sh
   ```

3. Issue a credential for the examples. Sign in to the console, open the `local-demo` workspace's **Members** page and, under **Machine tokens**, choose **Issue token**. Name it `examples` and select **Read content**, **Write content** and **Promote releases**. The secret is shown once. Export it:

   ```sh
   export ACCLIMATE_TOKEN='acm_…'
   ```

   The support agent needs only read and write. The ticket triage script also publishes a bundle, changes learning settings and starts the loop, and each of those needs promote.

4. Install what your language needs, from the repository root.

<Tabs items={['TypeScript', 'Python']}>
<Tab value="TypeScript">

Use Node.js 22.22 or later. The examples import the SDK from the checkout.

```sh
npm ci --ignore-scripts
```

</Tab>


## How a learning rollout runs your bundle

The learning executor renders a bundle as one system prompt. Instructions come first, then skills, then memory, and each file sits under a `# path` heading. The task input becomes the user message, and the model's reply is the output that gets graded.

The support agent builds its prompt the same way, in `prompt.ts` and in `system_prompt` in `agent.py`. If your application assembles the prompt differently, or runs a different model from the loop's task model, the loop measures a different agent from the one you run.
