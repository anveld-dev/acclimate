The repository's [`examples/`](https://github.com/anveld-dev/acclimate/tree/main/examples) directory holds small programs a developer can run against their own service. This page lists them and covers the setup the two learning walkthroughs share.

| Example | What you do | Read |
| --- | --- | --- |
| `examples/support-agent/`, `examples/learning/` | Answer a support request, improve the bundle with 60 sample tasks and report a correction as a task. TypeScript and Python. | [Support agent](/docs/examples/support-agent) |
| `examples/ticket-triage/` | Publish a bundle, import 64 labelled tickets and follow the learning loop from one script. TypeScript and Python. | [Ticket triage](/docs/examples/ticket-triage) |
| `examples/delivery-check.ts`, `python/examples/delivery_check.py` | Prepare the released version and read back the verified files. | [Connect your application](/docs/get-started/quickstart#connect-your-application) |
| `examples/publish.ts` | Create and release a bundle from a payload file. | [Publish a bundle from a file](/docs/guides/release-and-roll-back#publish-a-bundle-from-a-file) |
| `examples/claude-agent.ts`, `codex-agent.ts`, `cursor-agent.ts` | Run a coding agent on the prepared files. | [Claude Agent SDK](/docs/integrations/claude-agent-sdk), [Codex](/docs/integrations/codex), [Cursor](/docs/integrations/cursor) |
| `examples/native-repository/` | Stage an existing repository for a coding agent, with an offline replay. | [Prepare an existing repository](/docs/guides/deliver-content#prepare-an-existing-repository) |

For a quick end-to-end run, start with ticket triage. Its measured first round took 14 minutes, against about 95 for the support agent. See [What a round costs](/docs/concepts/how-it-works#what-a-round-costs).

## Set up once

Both walkthroughs use the local stack and a source checkout, or any Acclimate service if you set the same variables.

1. Start the local stack and give it a model. See [The local stack](/docs/get-started/run-locally) and [Set up a local model proxy](/docs/get-started/first-learning-round#set-up-a-local-model-proxy), which gives the service an optimizer and the workspace a verified model provider. The support agent's first step needs only a model endpoint for the application.

2. In the shell you run the examples from, load the stack's client settings. They set `ACCLIMATE_URL` and `ACCLIMATE_WORKSPACE` and make Node.js and Python trust the stack's certificate.

   ```sh
   source .local/stack/env.sh
   ```

3. Sign in to the console and open the `local-demo` workspace's **Members** page. Under **Machine tokens**, choose **Issue token**, name it `examples` and tick the [rights](/docs/concepts/credentials#rights) below. The secret is shown once, so export it straight away.

   | Example | Rights to tick |
   | --- | --- |
   | Support agent | **Read content** and **Write content** |
   | Ticket triage | **Read content**, **Write content** and **Promote releases** |

   ```sh
   export ACCLIMATE_TOKEN='<machine-token>'
   ```

4. From the repository root, install what your language needs. See [Install the SDKs](/docs/get-started/install) for runtime versions.
