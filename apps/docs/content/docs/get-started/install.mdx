title: Install the SDKs
description: Install the TypeScript or Python SDK from its registry, from verified release files or from a source checkout.
---

This page installs the TypeScript or Python SDK in the environment that runs your agent. It is for developers adding Acclimate to an application.

Most readers install from the registry. Use release files on an air-gapped machine, or when your operator distributes Acclimate directly. Build from source when you are changing the SDK. Use the SDK release that matches your service's version. See [Versioning and compatibility](/docs/reference/versioning).

## Prerequisites

| To use | You need |
| --- | --- |
| The TypeScript SDK and its `acclimate` command | Node.js 22.22 or later |
| The Python SDK and its `acclimate` command | Python 3.11 or later |
| Preparing files for a job | Linux or macOS, and a private local directory to stage the files in |

## Install from the registry

<Tabs items={['TypeScript', 'Python']}>
<Tab value="TypeScript">

```sh
npm install @acclimate/sdk
npx acclimate pull --help
```

`acclimate pull` saves a released version to a file. See [acclimate pull](/docs/reference/typescript-sdk#acclimate-pull).

To run Codex, the Claude Agent SDK, Pi or Cursor on the delivered files, also install the matching plugin, such as `@acclimate/codex-plugin`. See [Choose a native integration](/docs/guides/deliver-content#choose-a-native-integration).

</Tab>
<Tab value="Python">

The SDK uses only the standard library and needs no Node.js.

```sh
python3.11 -m venv .venv
.venv/bin/python -m pip install acclimate-sdk
.venv/bin/acclimate --help
```

The distribution is named `acclimate-sdk`. Import it as `acclimate`. The `acclimate` command and `python -m acclimate` run the same CLI. See [acclimate pull](/docs/reference/python-sdk#acclimate-pull).

On Python 3.10 or earlier, importing the package fails with a message that names the version it found.

</Tab>
</Tabs>

An Acclimate release can reach GitHub Releases before npm and PyPI. If your version is not on the registry yet, install from the release files.

## Install from verified release files

1. Choose a version on the [GitHub Releases page](https://github.com/anveld-dev/acclimate/releases).
2. Download `manifest.json`, `SHA256SUMS` and every file that `SHA256SUMS` lists into one directory.
3. From that directory, verify the files before you install anything.

   ```sh
   sha256sum --check SHA256SUMS        # Linux
   shasum -a 256 --check SHA256SUMS    # macOS
   ```

4. Install the file for your language. The examples use Acclimate release 0.1.0.

<Tabs items={['TypeScript', 'Python']}>
<Tab value="TypeScript">

Run the install command from your application's directory. The SDK tarball has no npm runtime dependencies.

```sh
npm install --offline --ignore-scripts /absolute/path/to/release/acclimate-sdk-0.1.0.tgz
./node_modules/.bin/acclimate pull --help
```

</Tab>
<Tab value="Python">

Install the wheel without contacting a package index.

```sh
python3.11 -m venv .venv
.venv/bin/python -m pip install --no-index --no-deps /absolute/path/to/release/acclimate_sdk-0.1.0-py3-none-any.whl
.venv/bin/acclimate --help
```

</Tab>
</Tabs>

## Build from a source checkout

### Build every artifact

From the repository root, build every artifact and check it against isolated consumers. This needs Node.js 22.22 or later and Python 3.11 or later.

```sh
npm ci --ignore-scripts
npm run pack:verify
```

The command writes the SDK and plugin tarballs, the Python wheel, the starter archives, the manifest and the checksums to `artifacts/releases/<version>/`. To build the same version again, pass `-- --output /path/to/new-release` to `npm run pack:verify`.

Install the tarball or the wheel with the commands under [Install from verified release files](#install-from-verified-release-files).

### Build only the Python wheel

Building the wheel needs only Python. Write the output outside the checkout:

```sh
python3.11 -m pip wheel --no-deps --wheel-dir /tmp/acclimate-wheel ./python
# or, with uv
uv build --wheel --out-dir /tmp/acclimate-wheel ./python
```

The build leaves no `build/` or `.egg-info` directories in the checkout. It downloads the `flit_core` build backend unless your index or cache already has it.

Install the wheel with the offline `pip install` command above. To install straight from the checkout instead, run `pip install ./python`.
