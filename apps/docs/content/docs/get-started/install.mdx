Install the SDK where your agent runs. Use the SDK version that matches your service's minor version. See [Versioning and compatibility](/docs/reference/versioning).

## Prerequisites

| To use | You need |
| --- | --- |
| The TypeScript SDK and its `acclimate` command | Node.js 22.22 or later |
| The Python SDK | Python 3.11 or later |
| Preparing files for a job | Linux or macOS, and a private local directory to stage the files in |

`@anveld/acclimate-sdk` is an ES module only. CommonJS code loads it with `await import('@anveld/acclimate-sdk')`.

## Install from the registry

The TypeScript SDK and all four plugins are public on npm. For an Acclimate 0.3.0 service, run this from your application's directory.

```sh
npm install @anveld/acclimate-sdk@0.3.0
npx acclimate --help
```

| Package | Use |
| --- | --- |
| [`@anveld/acclimate-sdk`](https://www.npmjs.com/package/@anveld/acclimate-sdk) | TypeScript SDK and `acclimate` CLI |
| [`@anveld/acclimate-codex-plugin`](https://www.npmjs.com/package/@anveld/acclimate-codex-plugin) | Codex |
| [`@anveld/acclimate-claude-plugin`](https://www.npmjs.com/package/@anveld/acclimate-claude-plugin) | Claude Agent SDK |
| [`@anveld/acclimate-pi-plugin`](https://www.npmjs.com/package/@anveld/acclimate-pi-plugin) | Pi |
| [`@anveld/acclimate-cursor-plugin`](https://www.npmjs.com/package/@anveld/acclimate-cursor-plugin) | Cursor |

Install any plugin at the same version as the SDK. [Use a coding agent](/docs/guides/coding-agents#install) has the commands for each integration.

## Install the Python SDK

The Python distribution is [`acclimate-sdk`](https://pypi.org/project/acclimate-sdk/), imported as `acclimate`. It uses only the Python standard library. These commands install the SDK for an Acclimate 0.3.0 service.

```sh
python3.11 -m venv .venv
.venv/bin/python -m pip install acclimate-sdk==0.3.0
.venv/bin/python -m acclimate pull --help
```

For offline installation, use the [verified release wheel](#install-from-verified-release-files).

## Build from a source checkout

```sh
git clone https://github.com/anveld-dev/acclimate.git
cd acclimate
```

### Build every artifact

```sh
npm ci --ignore-scripts
npm run pack:verify
```

This writes the SDK and plugin tarballs, the Python wheel, the starter archives, the manifest and the checksums to `artifacts/releases/<version>/`, and checks them against isolated consumers. To build the same version again, add `-- --output /path/to/new-release`.

### Build only the Python wheel

This needs only Python. Write the output outside the checkout:

```sh
python3.11 -m pip wheel --no-deps --wheel-dir /tmp/acclimate-wheel ./python
```

The build downloads the `flit_core` build backend unless your index or cache has it. You can also install straight from the checkout with `pip install ./python`.

### Install the files

Run this from your application's directory. `/absolute/path/to/release` is `artifacts/releases/<version>/` in your checkout, or the directory holding downloaded release files. The examples use version 0.3.0.

## Install from verified release files

1. Choose a version on the [GitHub Releases page](https://github.com/anveld-dev/acclimate/releases).
2. Download `manifest.json`, `SHA256SUMS` and every file that `SHA256SUMS` lists into one directory.
3. From that directory, verify the files.

   ```sh
   sha256sum --check SHA256SUMS        # Linux
   shasum -a 256 --check SHA256SUMS    # macOS
   ```

4. Install the file for your language as in [Install the files](#install-the-files).
