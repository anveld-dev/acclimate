This page takes you from a source checkout to a running Acclimate stack and one verified delivery. It is for a developer who wants to see delivery work before adding the SDK to an application.

You need:

- Docker, running. See [Prerequisites](/docs/get-started/run-locally#prerequisites) for the versions.
- Node.js 22.22 or later with npm.
- Python 3.9 or later.

## Start the stack

From the root of the checkout, run:

```sh
npm run local:up
npm run local:trust
```

`local:up` starts the service, the console and sign-in. The first start takes a few minutes, or 10 to 20 minutes when it has to build from source. It prints the console URL, a login and the login's initial password.

`local:trust` makes your browser trust the stack's HTTPS certificate. It asks you to type `trust` and may ask for your password.

Open the printed console URL and sign in. You land in the `local-demo` workspace. It already holds a [bundle](/docs/concepts/glossary) named **Example agent**, which is one instruction file released on the `stable` channel.

## Connect your application

A connection links one application to one bundle and channel. The application needs the connection's ID and a connection credential.

1. In the console, open **Connections** and choose **New connection**. Enter a display name, choose the **Example agent** bundle and the `stable` channel, then choose **Create connection**. The console opens the connection's **Setup** tab.

2. Under **Read credential**, choose **Create read credential**. The secret is shown once, so copy it now.

3. Open the connection's **Settings** tab and copy the **Connection ID**.

4. In a shell at the root of the checkout, install the Node.js dependencies and load the stack's client settings.

   ```sh
   npm ci --ignore-scripts
   source .local/stack/env.sh
   ```

   `env.sh` sets `ACCLIMATE_URL`, `ACCLIMATE_WORKSPACE` and `BUNDLE_ID`. It also makes Node.js and Python trust the stack's certificate.

5. Set the remaining variables and run the delivery check.

   ```sh
   export ACCLIMATE_BUNDLE="$BUNDLE_ID"
   export ACCLIMATE_CONNECTION='<connection-id>'
   export ACCLIMATE_TOKEN='<credential-secret>'
   export ACCLIMATE_SCOPE='quickstart'
   npm run example:delivery
   ```

   `ACCLIMATE_SCOPE` is a stable name for this application. The SDK uses it to keep the application's cache separate.

The check resolves `stable` to a version, downloads it, verifies it against its digest, reads every prepared file and cleans up. It makes no model calls. It prints one line:

```json
{"versionId":"<version-id>","digest":"<digest>","files":["instructions.md"],"checkedFiles":1,"reporting":"disabled"}
```

`reporting` is `disabled` because the check has no receipt credential. The script is `examples/delivery-check.ts`. The connection's **Setup** tab offers the same check as one file to download for your own application, in TypeScript or Python, under **First delivery**.

## Publish your own bundle

1. Open **Bundles** and choose **New bundle**.
2. Choose **Write instructions**, **Import files** or **Import JSON**. In imported files, skills go under `skills/` and memory under `memory/`.
3. Enter a bundle name, an initial channel and a compatibility target: Generic, Codex, Claude, Pi or Cursor.

Creating the bundle publishes its first version and releases it on that channel. Create a connection for it as you did above.
