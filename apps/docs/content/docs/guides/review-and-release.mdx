title: Inspect automatic releases
description: Follow a connected learning round from its evidence to the version served to new jobs.
---

An administrator seeds the bundle and enrolls the app connection. The app runs an evaluator on its own tasks. When a correction is ready, Acclimate proposes a change and compares it with the version the connection currently serves. [Set up connected learning](/docs/guides/connected-learning)

## Follow a change

Open **Connections**, choose the app, and open **Learning**. Each round shows its candidate, checks and outcome. A passing candidate advances the connection’s delivery revision automatically. A blocked candidate keeps its evidence and reason, and new jobs continue using the previous version.

Use **Changes** to inspect comparisons, file differences and case scores. To inspect recorded evidence in the terminal, run the operator CLI.

```sh
npm run operator -- review --workspace WORKSPACE --bundle BUNDLE --channel stable --comparison COMPARISON
```

## Follow delivery

Each new job resolves the enrolled connection once. A running job keeps the version it started with. Automatic rollback is enabled by default and uses field audit evidence to restore an earlier version. An administrator can stop learning to freeze delivery at its current version. [Monitor a release](/docs/guides/connected-learning#monitor-a-release)
