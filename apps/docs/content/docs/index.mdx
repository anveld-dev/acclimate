---
title: Acclimate
description: Version, deliver and automatically improve an AI agent's instructions, skills and memory files.
---

**Acclimate stores your agent's instructions, skills and memory files as versioned bundles and delivers the released version to each job your application starts.** It can also improve a bundle automatically from example tasks. It is open source and self-hosted.

- **Delivery.** Publish the files as a bundle and release a version to a channel such as `stable`. When your application starts a job, the SDK fetches that version, verifies it and writes the files for your agent. To undo a release, roll the channel back to an earlier version.
- **Learning.** Give a bundle tasks with expected answers. In each round the service proposes five changed versions and scores them on the tasks. It then releases the one it selects or keeps the current version. There is no approval step. Held-out tasks, which the loop never learns from, check every release, and a confirmed drop reverts it.

Your application still runs the agent with its own model credentials. Acclimate supplies the files.
