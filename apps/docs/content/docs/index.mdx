title: Acclimate
description: Version, evaluate, and release the instructions, skills, and approved memory your agent uses.
---

Use Acclimate to test changes to your agent's instructions, skills, and approved memory on real tasks before releasing them. Your application runs the agent and grades its work. Acclimate delivers pinned content and records the evidence and release decisions in your workspace.

## From edit to delivery

1. **Version.** Save the proposed files as an immutable candidate version of a bundle.
2. **Compare.** Run the candidate and its parent on the same saved cases with the same grader.
3. **Review.** Inspect the file changes, paired scores, missing evidence, and any recorded policy verdict.
4. **Release.** Make the reviewed version available on a channel, or restore an earlier version through a new release.
5. **Deliver.** Resolve and verify the selected version when your application prepares its next job. Jobs already started keep their pinned content.
