---
title: Acclimate
description: Version, deliver and automatically improve an AI agent's instructions, skills and memory files.
---

**Acclimate stores your agent's instructions, skills and memory files as versioned bundles and delivers the released version to each job your application starts.** It can also improve a bundle automatically from example tasks. It is open source and self-hosted.

- **Delivery.** Release a version of a bundle to a channel such as `stable`. When a job starts, the SDK fetches that version, verifies it and writes the files for your agent. To undo a release, roll the channel back.
- **Learning.** Give a bundle tasks with expected answers. Each round the service proposes five changed versions, scores them and releases the one it selects or keeps the current version. There is no approval step. Held-out tasks, which the loop never learns from, check every release, and a confirmed drop reverts it.

Your application still runs the agent with its own model credentials.
