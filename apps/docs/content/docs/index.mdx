**Ship changes to your agent's prompts, skills, and memory like code: versioned, A/B-graded on your own tasks, gated before release, and roll-backable.**

You save each change as a new version. Your agent runs the current version and the new one on the same saved tasks, your grader scores both, and the change ships only when the evidence clears your bar. If something goes wrong later, you release the earlier version again.

## How it differs from eval tools

Tools such as promptfoo, Braintrust, LangSmith, and Inspect run evaluations and track scores. Acclimate covers what happens around the evaluation. It stores your agent's content as immutable versions, pairs each change with the version it replaces, gates the release on those paired results, and delivers the released version to your application's next job. Your application still runs the agent and grades its work, so you can keep using an eval tool inside your grader.

Acclimate is open source under Apache-2.0 and self-hosted. Your agents, prompts, tasks, and model credentials stay in your environment.

## From edit to delivery

1. **Version.** Save the proposed files as a candidate version. It records the version it changes, its parent.
2. **Compare.** Your evaluator runs the parent and candidate on the same saved tasks with the same grader.
3. **Review.** Inspect the file changes, the paired scores, any missing evidence, and your policy's verdict.
4. **Release.** Point a channel such as `stable` at the reviewed version, or roll back by releasing an earlier one.
5. **Deliver.** Your application gets the released version for each new job. Jobs already running keep the content they started with.
