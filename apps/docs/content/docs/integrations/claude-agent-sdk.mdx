Use `@acclimate/claude-plugin` when your application runs agents with the Claude Agent SDK. The plugin writes a verified bundle version into a private directory in the layout Claude reads as a project, and your application runs the query there.

| Requirement | Value |
| --- | --- |
| Plugin | `@acclimate/claude-plugin`, with a `/native` entry point for the session options |
| Agent SDK | `@anthropic-ai/claude-agent-sdk`. The checked version is 0.3.325. |
| Node.js | 22.22 or later. See [Install the SDKs](/docs/get-started/install#prerequisites). |
| Platform | Linux or macOS |

## Install

The plugin does not depend on the Claude Agent SDK. Install the agent SDK yourself, next to the plugin and the Acclimate SDK.

```sh
npm install @acclimate/sdk @acclimate/claude-plugin @anthropic-ai/claude-agent-sdk
```

The plugin and the Acclimate SDK must come from the same Acclimate release. To install them from release files, see [Install from verified release files](/docs/get-started/install#install-from-verified-release-files).

## Files the plugin writes

`prepare` creates a new private directory for each job and writes the version's files into it.

| Bundle file | Written to |
| --- | --- |
| Instruction | `CLAUDE.md` |
| Skills | `.claude/skills/<name>/`, with their supporting files |
| Memory | `.acclimate/memory/` |

Claude does not load the memory files. `prepared.memoryFiles` lists each one with its `path`, `text` and `absolutePath`. Add the ones you choose to the prompt.

A version must follow the [rules for bundle files](/docs/guides/deliver-content#rules-for-bundle-files), or `prepare` fails before it writes anything.

## Prepare and run a query

Pass the result of `client.prepare()` to the plugin's `prepare`. [Choose a native integration](/docs/guides/deliver-content#choose-a-native-integration) explains what else `prepare` accepts. Your application supplies `client`, the IDs, `model`, `prompt` and the permissions.

```ts
import { query } from '@anthropic-ai/claude-agent-sdk';
import { prepare } from '@acclimate/claude-plugin';
import { claudeSessionOptions } from '@acclimate/claude-plugin/native';

const delivery = await client.prepare({ workspaceId, bundleId, channel: 'stable', reporter });
const prepared = await prepare(delivery);
const abortController = new AbortController();
for await (const message of query({
  prompt,
  options: {
    ...claudeSessionOptions(prepared),
    model,
    abortController,
    permissionMode: 'dontAsk',
    allowedTools: ['Read', 'Edit', 'Write', 'Glob', 'Grep', 'Bash'],
    sandbox: { enabled: true },
  },
})) {
  if (message.type === 'system' && message.subtype === 'init') prepared.reportStarted();
}
await prepared.cleanup();
```

- `claudeSessionOptions` returns `cwd`, `settingSources: ['project']` and the version's skill names as `skills`. It leaves out `skills` when the version has none, because an empty list disables every skill.
- `prepared.reportStarted()` queues the delivery's start receipt. It returns `null` when `client.prepare()` had no `reporter`. See [Report job starts](/docs/guides/deliver-content#report-job-starts).
- Save the result with `prepared.versionId` and `prepared.digest` before you clean up.
- `prepared.cleanup()` removes the directory and releases the delivery. Call it only after the query has finished. If the query rejects, its process may still be running, so keep the files for inspection.

The repository's [`examples/claude-agent.ts`](https://github.com/anveld-dev/acclimate/blob/main/examples/claude-agent.ts) shows the complete job, including receipts and saving the result.

## Use your repository's settings

The query runs in a new directory, so your repository's `.claude/settings.json`, `.mcp.json`, hooks and subagents do not apply by default. Pass `baseDir` to copy them in:

```ts
const prepared = await prepare(delivery, { baseDir: '/absolute/path/to/repository' });
```

| Copied from `baseDir` | Never copied |
| --- | --- |
| `.claude/settings.json` | `CLAUDE.md` |
| `.claude/agents/` | `CLAUDE.local.md` |
| `.claude/commands/` | `.claude/skills/` |
| `.claude/hooks/` | `.claude/settings.local.json` |
| `.claude/output-styles/` | |
| `.mcp.json` | |

Instructions and skills still come only from the bundle. `prepared.overlayFiles` lists the copied files with their SHA-256 digests. Record them with the job's result, because hooks and MCP servers change how the agent behaves.

## Use the native repository starter

The starter runs Claude with `"harness": "claude"`. See [Prepare an existing repository](/docs/guides/deliver-content#prepare-an-existing-repository).
