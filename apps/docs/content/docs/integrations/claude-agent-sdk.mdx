Prepare a Claude project workspace using `@acclimate/claude-plugin`. Install the plugin tarball with the matching [Acclimate SDK](/docs/get-started/install); both come from the same release, and the SDK is a peer of the plugin. The `/native` entry targets the optional peer `@anthropic-ai/claude-agent-sdk` `^0.3.325`.

## Where the verified version comes from

`prepare` takes a verified version, the SDK's checked copy of a version's bytes:

- In a job, `client.prepare()` resolves the channel, verifies the digest and returns a delivery. Pass the delivery itself so its start receipt survives.
- With `resolveAndCache(client, selection, { cacheDir })` you get the verified version directly.

## Run a job

The plugin writes the instruction to `CLAUDE.md`, skills to `.claude/skills/<name>/` with their supporting files, and memory files to `.acclimate/memory/`. `claudeSessionOptions` returns `cwd`, `settingSources: ['project']` and the version's skill names. It leaves out `skills` when the version has none, because an empty list disables every skill.

```ts
import { query } from '@anthropic-ai/claude-agent-sdk';
import { prepare } from '@acclimate/claude-plugin';
import { claudeSessionOptions } from '@acclimate/claude-plugin/native';

const delivery = await client.prepare({ workspaceId, bundleId, channel: 'stable', reporter });
const prepared = await prepare(delivery);
const abortController = new AbortController();
for await (const message of query({
  prompt,
  options: {
    ...claudeSessionOptions(prepared),
    model,
    abortController,
    permissionMode: 'dontAsk',
    allowedTools: ['Read', 'Edit', 'Write', 'Glob', 'Grep', 'Bash'],
    sandbox: { enabled: true },
  },
})) {
  if (message.type === 'system' && message.subtype === 'init') prepared.reportStarted();
}
await prepared.cleanup();
```

Supply your own model, prompt and permissions. Add selected approved memory through your app's context. `prepared.cleanup()` removes the workspace and releases the delivery. Call it only after the query finished: if the query rejects, its process may still be running, so keep the files for inspection.

## Use your repository's settings

The session runs in a fresh directory, so your repository's `.claude/settings.json`, `.mcp.json`, hooks and subagents do not apply by default. Pass `baseDir` to copy them in:

```ts
const prepared = await prepare(delivery, { baseDir: '/absolute/path/to/repository' });
```

This copies `.claude/settings.json`, `.claude/agents/`, `.claude/commands/`, `.claude/hooks/`, `.claude/output-styles/` and `.mcp.json`. Instructions and skills still come only from the bundle: `CLAUDE.md`, `CLAUDE.local.md`, `.claude/skills/` and `.claude/settings.local.json` are never copied. `prepared.overlayFiles` lists the copied files with their SHA-256 digests. Record them in your runtime identity, because hooks and MCP servers change behavior.

## Qualification

Offline checks verify staged files, the settings overlay and receipts, and typecheck the options and the example against SDK 0.3.325. The starter's Claude adapter is checked against a fake SDK module. Live Claude provider sessions remain unqualified.
