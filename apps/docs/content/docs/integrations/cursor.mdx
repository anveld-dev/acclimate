Prepare local project resources for a Cursor agent with `@acclimate/cursor-plugin`. Install the plugin tarball with the matching [Acclimate SDK](/docs/get-started/install). The `/native` entry targets optional peer `@cursor/sdk` 1.3.1, which requires Node.js 22.13 or later.

## Prepare a local workspace

The instruction goes to `AGENTS.md`, and skills go under `.cursor/skills/`. Cursor skill names use lowercase letters, digits, and hyphens. Pass the bundle paths of approved memory you want staged. Your app chooses how to include that memory in the prompt or context.

```ts
import { prepare } from '@acclimate/cursor-plugin';
import { cursorLocalOptions } from '@acclimate/cursor-plugin/native';

const prepared = await prepare(verifiedVersion, { approvedMemoryPaths });
const options = cursorLocalOptions(prepared);
```

Pass the returned `local.cwd` and `local.settingSources: ['project']` to `Agent.create` with your app's credentials, model, and permissions. Start a fresh local agent for a new version. Call `await prepared.cleanup()` when the agent stops. Cleanup removes the prepared directory, including any files the agent created, so retain needed results first.

## Qualification

Offline checks cover native option types and file preparation. Live provider sessions, scanner discovery, and resumed-session reload behavior remain unqualified. The plugin prepares local files. Cloud delivery is outside its supported scope.
