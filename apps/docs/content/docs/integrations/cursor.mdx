Use `@acclimate/cursor-plugin` when your application runs local agents with the Cursor SDK. The plugin writes a verified bundle version into a private directory in the layout Cursor reads, and your application creates the agent there. Cursor cloud agents are not supported.

| Requirement | Value |
| --- | --- |
| Plugin | `@acclimate/cursor-plugin`, with a `/native` entry point for the agent options |
| Agent SDK | `@cursor/sdk` `^1.3.1`, an optional peer that only the `/native` entry point uses |
| Runtime | Node.js 22.22 or later on Linux or macOS. See [Install the SDKs](/docs/get-started/install#prerequisites). |

## Install

Install the agent SDK beside the plugin and the Acclimate SDK. The plugin and the Acclimate SDK must come from the same Acclimate release.

```sh
npm install @acclimate/sdk @acclimate/cursor-plugin @cursor/sdk
```

For release files, see [Install from verified release files](/docs/get-started/install#install-from-verified-release-files).

## Files the plugin writes

`prepare` writes each job's files into a new private directory. It fails before writing anything if the version breaks the [rules for bundle files](/docs/guides/deliver-content#rules-for-bundle-files), which allow Cursor only lowercase skill names.

| Bundle file | Written to |
| --- | --- |
| Instruction | `AGENTS.md` |
| Skills | `.cursor/skills/<name>/`, with their supporting files |
| Memory | `.acclimate/memory/`, only the files you name in `approvedMemoryPaths` |

Cursor does not load the memory files. Pass the bundle paths of the ones you want as `approvedMemoryPaths`, and `prepare` fails if one is not a memory file in the version. Add the ones you choose from `prepared.memoryFiles` to the prompt. Each entry has a `path`, `text` and `absolutePath`.

## Prepare and run an agent

Pass the delivery from `client.prepare()` to the plugin's `prepare`, which accepts the inputs in [Choose a native integration](/docs/guides/deliver-content#choose-a-native-integration). Your application supplies `client`, the IDs, `apiKey`, `model`, `prompt` and `approvedMemoryPaths`.

```ts
import { Agent } from '@cursor/sdk';
import { prepare } from '@acclimate/cursor-plugin';
import { cursorLocalOptions } from '@acclimate/cursor-plugin/native';

const delivery = await client.prepare({ workspaceId, bundleId, channel: 'stable', reporter });
const prepared = await prepare(delivery, { approvedMemoryPaths });
const agent = await Agent.create({
  apiKey,
  model: { id: model },
  local: { ...cursorLocalOptions(prepared).local, sandboxOptions: { enabled: true } },
});
let result;
try {
  const run = await agent.send(prompt);
  let started = false;
  for await (const event of run.stream()) {
    if (!started && event.type === 'status' && event.status === 'RUNNING') {
      started = true;
      prepared.reportStarted();
    }
  }
  result = await run.wait();
} finally {
  await agent[Symbol.asyncDispose]();
}
await prepared.cleanup();
```

- Create a new local agent for each job. `cursorLocalOptions` returns the `local` fields `cwd` and `settingSources: ['project']`.
- Cursor's local sandbox is off unless you set `sandboxOptions: { enabled: true }` beside those fields, as the sample does.
- `prepared.reportStarted()` queues the start receipt, or returns `null` without a `reporter`. See [Report job starts](/docs/guides/deliver-content#report-job-starts).
- Save `result.status` and `result.result` with `prepared.versionId` and `prepared.digest`. Then `prepared.cleanup()` removes the directory, including files the agent created, and releases the delivery.
- Clean up only after `run.wait()` has returned. If the run's end is unknown, keep the files for inspection.

[`examples/cursor-agent.ts`](https://github.com/anveld-dev/acclimate/blob/main/examples/cursor-agent.ts) shows the complete job, including receipts and saving the result.

## Use the native repository starter

The starter runs Cursor with `"harness": "cursor"` and the sandbox enabled. See [Prepare an existing repository](/docs/guides/deliver-content#prepare-an-existing-repository).
