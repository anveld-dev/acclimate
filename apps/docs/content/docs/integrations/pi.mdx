Prepare resources for a Pi session with `@acclimate/pi-plugin`. Install the plugin tarball with the matching [Acclimate SDK](/docs/get-started/install); the SDK is a peer of the plugin. The `/native` entry uses optional peer `@earendil-works/pi-coding-agent` `^1.5.2` and requires Node.js 22.19 or later. Preparation-only imports do not load the Pi SDK.

## Load the prepared resources

The main entry returns a private working directory and resource descriptors for the instruction, skills, and memory. It accepts a verified version or the result of `client.prepare()`. The native entry builds and reloads Pi's resource loader. Pass source paths for the memory you approve as appended context. The default list is empty.

```ts
import { prepare } from '@acclimate/pi-plugin';
import { createPiResourceLoader } from '@acclimate/pi-plugin/native';

const prepared = await prepare(delivery);
const loader = await createPiResourceLoader(prepared, ['memory/selected.md']);
```

Use the returned loader when your app creates a fresh session with `createAgentSession`, and limit its `tools`. Replace the example memory path with one in your bundle or omit the list. Call `prepared.reportStarted()` when the session starts, keep the working directory until the session stops using it, then call `await prepared.cleanup()`.

The [native repository starter](/docs/guides/deliver-content#prepare-an-existing-repository) runs Pi with `"harness": "pi"` and a `provider/model-id` model value.

## Qualification

Offline checks exercise Pi's actual resource loader, including explicit memory selection, and the starter's adapter against a fake SDK module. Live Pi provider sessions remain unqualified.
