---
title: Manage machine tokens
description: Issue, rotate and revoke workspace credentials for applications and automation.
---

In **Members**, workspace administrators use **Machine tokens** to issue a credential with a name, rights, and expiry. Copy the token on issuance or rotation and store it in a secret manager. Rotating preserves the machine principal. The old secret expires after the chosen overlap period. Revoking a token removes its access.

| Right | Access |
| --- | --- |
| `read` | Read workspace metadata, versions and payloads. |
| `evaluate` | Includes `read`. |
| `write` | Upload versions and create bundles. Includes `evaluate`. |
| `promote` | Move a channel to a version. |

For a delivery credential scoped to one bundle and channel, issue a content-read credential from **Connections**. Use a separate reporting credential to submit optional delivery receipts. [Delivery setup](/docs/guides/deliver-content)

The [HTTP API](/docs/reference/http-api) documents the machine-token routes. For static machine grants, configure `ACCLIMATE_AUTH` as described in [configuration](/docs/reference/configuration).
