Configure each process with its own credentials and addresses. Use the [deployment guide](/docs/operate/deploy) for the private runtime files and [evaluator access](/docs/operate/evaluator-access) for the worker config format.

## Application and CLI recipes

These variables are used by the repository's app setup recipes and command-line examples. In SDK code, pass the values to the client or preparation call.

| Variable | Purpose |
| --- | --- |
| `ACCLIMATE_URL` | Public HTTPS API base URL. |
| `ACCLIMATE_TOKEN` | Scoped machine token for the operation. Use a delivery read token in the application. |
| `ACCLIMATE_SCOPE` | Stable app or authenticated principal identity for cache scoping. Keep it distinct from the token. |
| `ACCLIMATE_PROJECT`, `ACCLIMATE_BUNDLE`, `ACCLIMATE_CHANNEL` | Workspace ID, bundle ID, and channel used by the delivery examples. |
| `ACCLIMATE_CACHE`, `ACCLIMATE_JOB_DIR` | Cache and staging directory overrides in the console recipes. |
| `ACCLIMATE_INTEGRATION`, `ACCLIMATE_RECEIPT_TOKEN` | Connection ID and separate optional delivery reporting credential. |
| `ACCLIMATE_EVALUATOR_CASES` | Absolute path to a private JSON array that overrides the installed adapter's cases. Use mode 0600. |
| `ACCLIMATE_CI_PYTHON` | Override the Python interpreter used by the CI wrapper. |

`EVALUATOR_CONFIG` in command examples is a shell variable for the path passed to `--config`. The evaluator reads its credential and journal settings from that explicit private file.

## Rust service

| Variable | Purpose |
| --- | --- |
| `DATABASE_URL` | PostgreSQL connection URL for the service database. |
| `ACCLIMATE_BIND` | Private API listener address. |
| `ACCLIMATE_OIDC_ISSUER` | Exact HTTPS Keycloak realm issuer. |
| `ACCLIMATE_LOGIN_TOKEN`, `ACCLIMATE_CONSOLE_TOKEN` | Distinct login authority and console transport credentials. |
| `ACCLIMATE_OPERATORS` | JSON array of exact issuer and subject pairs for deployment operators. |
| `ACCLIMATE_AUTH` | JSON array of explicit machine grants. Use `[]` for browser-only operation. |
| `ACCLIMATE_MODEL_ENDPOINT`, `ACCLIMATE_MODEL_TOKEN`, `ACCLIMATE_MODEL` | Optional configuration for the service proposer. |
| `ACCLIMATE_LEARNING_MAX_STEPS_BETWEEN_AUDITS`, `ACCLIMATE_LEARNING_MAX_CHAIN_AGE_SECONDS` | When to check accumulated development changes before an audit. See `deploy/README.md` for learning policy and budget settings. |

## Console and Compose

| Variable | Purpose |
| --- | --- |
| `CONSOLE_ORIGIN` | Canonical public HTTPS console origin. |
| `CONSOLE_PUBLIC_API_URL` | Public HTTPS API URL shown in app setup. |
| `CONSOLE_SERVICE_URL` | Private console-to-API URL. |
| `CONSOLE_LOGIN_TOKEN`, `CONSOLE_SERVICE_TOKEN` | Match the Rust login authority and console transport credentials, respectively. |
| `CONSOLE_OIDC_ISSUER`, `CONSOLE_OIDC_CLIENT_ID`, `CONSOLE_OIDC_CLIENT_SECRET` | Exact Keycloak issuer and confidential client credentials. |
| `CONSOLE_ALLOW_EDITS` | Set to `true` to enable authorized authoring and connection mutations. |
| `CONSOLE_HOST`, `API_HOST`, `ACME_EMAIL` | Proxy hostnames without schemes or paths, and certificate contact address. |
| `ACCLIMATE_SERVICE_ENV`, `ACCLIMATE_CONSOLE_ENV`, `ACCLIMATE_POSTGRES_PASSWORD_FILE` | Absolute paths to the private files required by Compose. |

Remove `ACCLIMATE_MODE` and `CONSOLE_MODE` from the runtime environment. The current entry points reject defined values.
