Configure each process with its own credentials and addresses. Use the [self-hosting guide](/docs/operate/self-host) for the private runtime files and machine-token access for workspace credentials.

## Application and CLI recipes

The SDK’s job helpers read `ACCLIMATE_URL`, `ACCLIMATE_WORKSPACE` and `ACCLIMATE_TOKEN` directly. Other delivery variables below are app setup conventions. Read them in your app and pass them to the client or preparation call.

| Variable | Purpose |
| --- | --- |
| `ACCLIMATE_URL` | Public HTTPS API base URL. |
| `ACCLIMATE_TOKEN` | Scoped machine token for the operation. Use a delivery read token in the application. |
| `ACCLIMATE_SCOPE` | Stable app or authenticated principal identity for cache scoping. Keep it distinct from the token. |
| `ACCLIMATE_WORKSPACE`, `ACCLIMATE_BUNDLE`, `ACCLIMATE_CHANNEL` | Workspace ID, bundle ID, and channel used by the delivery examples. |
| `ACCLIMATE_CACHE`, `ACCLIMATE_JOB_DIR` | Cache and staging directory overrides in the console recipes. |
| `ACCLIMATE_CONNECTION`, `ACCLIMATE_RECEIPT_TOKEN` | Connection ID and separate optional delivery reporting credential. |
| `AGENT_TASK` | Task input for the console's connected agent recipe. |


## Rust service

| Variable | Purpose |
| --- | --- |
| `DATABASE_URL` | Required `postgresql://` or `postgres://` URL with an explicit host, user and database. URL-encode the password component. |
| `ACCLIMATE_BIND` | Private API socket address. Defaults to `127.0.0.1:3000`. Compose binds `0.0.0.0:3000` inside the private network. |
| `ACCLIMATE_OIDC_ISSUER` | Required exact HTTPS realm issuer. Match `CONSOLE_OIDC_ISSUER` verbatim, including any trailing slash. Do not include credentials, a query or a fragment. |
| `ACCLIMATE_LOGIN_TOKEN` | Required login authority token. Match `CONSOLE_LOGIN_TOKEN`. |
| `ACCLIMATE_CONSOLE_TOKEN` | Required console transport token. Match `CONSOLE_SERVICE_TOKEN`. Use a different token from the login authority and every machine grant. The login authority and machine tokens must also be distinct. |
| `ACCLIMATE_OPERATORS` | Required nonempty JSON array of objects with `issuer` and `subject`. Each pair must be unique, use the exact configured issuer and have a nonempty subject of at most 512 bytes. |
| `ACCLIMATE_AUTH` | Required JSON array of static machine grants with `token`, `principalId`, `workspaceId` and `rights`. Use `[]` when every machine token is issued from the console. Rights are `read`, `write` and `promote`.

A token identifies one principal and can appear once per workspace. Keep colons out of principal IDs. Changing this value requires a restart; console-issued machine tokens do not. |
| `ACCLIMATE_SERVICE_BINARY` | Absolute path to the executable used by the native `npm start` wrapper. Defaults to `target/release/acclimate-service` under the checkout. |

Remove `ACCLIMATE_MODE` and `CONSOLE_MODE` from both the Rust and console environments. Startup rejects any defined value.

### Learning

Run the `acclimate-executor` container with a provisioned `ACCLIMATE_EXECUTOR_TOKEN` and access to the Docker socket. Build the chat runner image and configure gVisor (`runsc`) in production. Set `ACCLIMATE_PROVIDER_ENCRYPTION_KEY` on the service to a 64-character hex key so workspace provider credentials can be encrypted at rest.

The failed-round threshold accept integers from 1 to 4,294,967,295. An unset or invalid value falls back to its default. Invalid optimizer timeout, token limit or reasoning effort settings prevent startup, even when the endpoint is unset.

| Learning setting | Purpose |
| --- | --- |
| `ACCLIMATE_MODEL_ENDPOINT` | Full HTTP or HTTPS OpenAI-compatible Chat Completions URL without embedded credentials, including `/v1/chat/completions` for CLIProxyAPI. An unset endpoint leaves the optimizer unavailable. |
| `ACCLIMATE_MODEL_TOKEN` | Nonblank optimizer endpoint bearer credential without control characters. Required when the endpoint is set. |
| `ACCLIMATE_MODEL` | Model for proposing, screening and selecting. Required when the endpoint is set. The trimmed model ID must have 1–256 bytes and no control characters. The round pins this value at its start. |
| `ACCLIMATE_MODEL_REASONING_EFFORT` | Optional reasoning effort for optimizer requests. Accepts `low`, `medium`, `high`, `xhigh`, `max` or `ultra`. The round pins this value at its start. When unset, requests omit `reasoning_effort`. |
| `ACCLIMATE_MODEL_TIMEOUT_SECONDS` | Timeout per optimizer HTTP attempt in seconds. Integer from 30 to 3,600, defaults to 600. |
| `ACCLIMATE_MODEL_MAX_COMPLETION_TOKENS` | Value sent as `max_completion_tokens` for each optimizer call. Integer from 1,024 to 262,144, defaults to 32,768. |
| `ACCLIMATE_LEARNING_MAX_FAILED_ROUNDS` | Consecutive failed rounds before the loop pauses. Defaults to 3. |

### CLIProxyAPI with Codex sign-in

Acclimate supports OpenAI-compatible Chat Completions endpoints for the optimizer. Follow the CLIProxyAPI setup guide and pin the proxy build. In the current v8 config, set `server.port` to `8317` (the default) and put a private client API key in `access.api-keys`. Bind the listener to an interface reachable by the service on a private network. Use loopback when both processes run directly on the same host. Inside Compose, use the proxy's reachable hostname since loopback refers to the service container. [CLIProxyAPI setup guide](https://help.router-for.me/) · [Example configuration](https://github.com/router-for-me/CLIProxyAPI/blob/f5c5681a8361c9da53e93c60b6507816eee7468b/config.example.yaml)

Run `cli-proxy-api -config /private/config.yaml -codex-login` to sign in with Codex, then start the proxy with `cli-proxy-api -config /private/config.yaml`. Check that the intended model ID is available to the signed-in account. [CLI flags](https://github.com/router-for-me/CLIProxyAPI/blob/f5c5681a8361c9da53e93c60b6507816eee7468b/cmd/server/main.go)

Set these values in the service environment.

| Setting | Value |
| --- | --- |
| `ACCLIMATE_MODEL_ENDPOINT` | Full URL, for example `http://127.0.0.1:8317/v1/chat/completions`. The service posts to the URL as written. |
| `ACCLIMATE_MODEL_TOKEN` | Required nonempty proxy client key from `access.api-keys`. The service sends it as a bearer token. |
| `ACCLIMATE_MODEL` | `gpt-6.2-astra` for the experiment, or the model ID served by your proxy. |
| `ACCLIMATE_MODEL_REASONING_EFFORT` | `high` for the experiment. |

The optimizer requests JSON mode and includes `max_completion_tokens` (default 32,768). The inspected CLIProxyAPI Codex translator maps `max_completion_tokens` to `max_output_tokens` and `reasoning_effort` to `reasoning.effort`. Its format switch has no `json_object` case, so JSON mode is unenforced on that route. The optimizer prompts for JSON and validates the returned content. The service retries HTTP 429, HTTP 5xx, and qualifying connection or timeout errors with 5- and 30-second backoffs. [Codex Chat Completions translator](https://github.com/router-for-me/CLIProxyAPI/blob/f5c5681a8361c9da53e93c60b6507816eee7468b/internal/translator/codex/openai/chat-completions/codex_openai_request.go)

### Invitation email

Set `ACCLIMATE_SMTP_HOST` to enable application invitation email. Configure Keycloak's email separately.

| Variable | Purpose |
| --- | --- |
| `ACCLIMATE_SMTP_HOST` | SMTP relay hostname. Required when another `ACCLIMATE_SMTP_*` variable is set. |
| `ACCLIMATE_SMTP_PORT` | Integer from 1 to 65,535. Defaults to 465 with `tls` and 587 otherwise. |
| `ACCLIMATE_SMTP_FROM` | Required sender mailbox when SMTP is enabled, for example `Acclimate <noreply@example.com>`. |
| `ACCLIMATE_SMTP_TLS` | `starttls` by default. Use `tls` for implicit TLS. The `none` setting requires `localhost`, `127.0.0.1`, `::1` or `mailpit`, with no SMTP credentials. |
| `ACCLIMATE_SMTP_USERNAME`, `ACCLIMATE_SMTP_PASSWORD` | Optional authentication. Set both to nonempty values for a TLS relay that requires credentials. |
| `ACCLIMATE_CONSOLE_ORIGIN` | Required HTTPS console origin when SMTP is enabled. Use the same public origin as `CONSOLE_ORIGIN` for invitation links. |

## Console

| Variable | Purpose |
| --- | --- |
| `CONSOLE_ORIGIN` | Required canonical public HTTPS origin without a path or trailing slash. The trusted proxy must supply this origin's host as `Host`. |
| `CONSOLE_PUBLIC_API_URL` | Required public HTTPS API base URL shown in app setup. |
| `CONSOLE_SERVICE_URL` | Required private HTTP or HTTPS API base URL. Use `http://service:3000` in Compose. |
| `CONSOLE_LOGIN_TOKEN` | Required. Match Rust's `ACCLIMATE_LOGIN_TOKEN`. |
| `CONSOLE_SERVICE_TOKEN` | Required. Match Rust's `ACCLIMATE_CONSOLE_TOKEN`. Use a different value from `CONSOLE_LOGIN_TOKEN`. |
| `CONSOLE_OIDC_ISSUER` | Required exact HTTPS realm issuer. Match `ACCLIMATE_OIDC_ISSUER` verbatim. |
| `CONSOLE_OIDC_CLIENT_ID`, `CONSOLE_OIDC_CLIENT_SECRET` | Required confidential client ID and credential. The bundled realm uses `acclimate-console`. Register the exact `CONSOLE_ORIGIN` plus `/auth/callback`. |
| `CONSOLE_ALLOW_EDITS` | Set to the literal `true` to enable authoring, connection and learning mutations for authorized users. Defaults to disabled. |
| `CONSOLE_WORKSPACE`, `CONSOLE_BUNDLE`, `CONSOLE_CHANNEL` | Optional fallback workspace, bundle and channel for server operations without a saved selection. Many operations use `stable` when a channel is absent. Prefer selecting the scope in the console. |
| `HOST`, `PORT` | Listener settings. The native console and dev wrappers default to `127.0.0.1` and `3100` and accept port numbers 1–65,535. Compose binds `0.0.0.0:3100` on the private network. |
| `NODE_ENV` | The console image runs with `production`. |

The console derives `CONSOLE_SESSION_TOKEN` from the request's session cookie. Set user access through OIDC sign-in. The built Node listener can also read Nitro's `NITRO_HOST`, `NITRO_PORT`, `NITRO_UNIX_SOCKET`, `NITRO_SSL_CERT` and `NITRO_SSL_KEY`. Leave those overrides unset for the bundled deployment so its health probe and proxy can reach the private HTTP listener.

## Compose and co-hosted Keycloak

| Variable | Purpose |
| --- | --- |
| `CONSOLE_HOST`, `API_HOST`, `KEYCLOAK_HOST` | Distinct public hostnames without schemes or paths. The Keycloak hostname is required with the co-hosted overlay. |
| `ACME_EMAIL` | Certificate contact email for Caddy. |
| `ACCLIMATE_SERVICE_ENV`, `ACCLIMATE_CONSOLE_ENV` | Absolute paths to the private service and console runtime files. |
| `ACCLIMATE_POSTGRES_PASSWORD_FILE` | Absolute path to the private raw PostgreSQL password file. Its password must match the encoded value in `DATABASE_URL`. |
| `ACCLIMATE_KEYCLOAK_ENV`, `ACCLIMATE_KEYCLOAK_POSTGRES_PASSWORD_FILE` | Absolute paths to the private Keycloak runtime file and separate raw database password file for the overlay. |
| `ACCLIMATE_VERSION` | Tag for the service and console images. Defaults to `latest`. Pin the exact release version without the Git tag's leading `v`, for example `0.1.0`. |
| `ACCLIMATE_SERVICE_IMAGE`, `ACCLIMATE_CONSOLE_IMAGE` | Optional complete image references. An explicit reference overrides the corresponding default GHCR image and version tag. |

In the Keycloak runtime file, set `KC_DB_PASSWORD` to the raw password from the identity database's password file. For the initial realm import, set `ACCLIMATE_CONSOLE_ORIGIN` and `ACCLIMATE_OIDC_CLIENT_SECRET` to the values of the console's `CONSOLE_ORIGIN` and `CONSOLE_OIDC_CLIENT_SECRET`. Set `KC_BOOTSTRAP_ADMIN_USERNAME` and `KC_BOOTSTRAP_ADMIN_PASSWORD` for the temporary administrator. See [Self-host Acclimate](/docs/operate/self-host) for the file setup and first sign-in.
