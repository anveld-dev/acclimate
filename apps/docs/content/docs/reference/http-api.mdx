Use the HTTP contract when integrating without an SDK or inspecting a response. [`contracts/openapi.json`](https://github.com/anveld-dev/acclimate/blob/main/contracts/openapi.json) is the OpenAPI 3.1 source of truth for routes, request and response bodies, status codes and error codes. [`contracts/bundle.schema.json`](https://github.com/anveld-dev/acclimate/blob/main/contracts/bundle.schema.json) describes bundle payloads.

The SDKs ship the same shapes. In TypeScript, import the types from `@acclimate/sdk`; their declarations are in `node_modules/@acclimate/sdk/dist/types.d.ts`. In Python, import them from `acclimate` or `acclimate.types`. JSON fields are camelCase in every language. See [versioning and compatibility](/docs/reference/versioning) for how the contract changes between releases.

## Workspace routes

Every workspace route starts with `/v1/workspaces/{workspaceId}`.

| Operation | Method and path relative to the workspace prefix |
| --- | --- |
| List or create bundles | `GET` or `POST /bundles` |
| Create a bundle, its first version and its first release | `POST /bundle-setups` |
| Create a version | `POST /bundles/{bundleId}/versions` |
| Read metadata or exact bytes | `GET /bundles/{bundleId}/versions/{versionId}` or the same path with `/payload` |
| List channels | `GET /bundles/{bundleId}/channels` |
| Resolve a channel | `GET /bundles/{bundleId}/channels/{channel}` |
| List or create releases | `GET` or `POST /bundles/{bundleId}/channels/{channel}/releases` |
| List or create connections | `GET` or `POST /connections` |
| List connection observations | `GET /connection-observations` |
| Issue or list machine tokens | `GET` or `POST /machine-tokens` |
| Rotate or revoke a machine token | `POST /machine-tokens/{tokenId}/rotate` or `POST /machine-tokens/{tokenId}/revoke` |
| List machine token events | `GET /machine-token-events` |
| Revoke a connection | `POST /connections/{connectionId}/revoke` |
| Issue or revoke a connection credential | `POST /connections/{connectionId}/credentials` or `POST /connections/{connectionId}/credentials/{credential}/revoke` |
| List or submit delivery receipts | `GET` or `POST /connections/{connectionId}/receipts` |
| Look up or close a retained write | `GET /operations/{operationId}` or `POST /operations/{operationId}/close` |

`GET /v1/workspaces` lists the workspaces the caller can access.

Machine requests carry an `Authorization: Bearer …` header and need the appropriate workspace grant. Use HTTPS for remote access. The unauthenticated [health endpoints](/docs/operate/health-and-readiness) sit outside the workspace prefix.

## Read and verify a version

Channel resolution returns a revision and immutable version metadata. Send the last ETag in `If-None-Match` for a conditional channel read. An HTTP 304 means the selected mapping was unchanged. Obtain the exact stored payload from `/payload`, verify its SHA-256 digest against the metadata before parsing, then validate the bundle schema. Re-encoding a JSON object can change the bytes.

Bundle entries are UTF-8 text with a portable relative path and a kind of `instruction`, `skill`, or `memory`. The contract allows up to 128 files, 256 KiB of text per file, and a 1 MiB bundle payload. Paths reject traversal and file or directory collisions.

```json title="Bundle payload"
{
  "schemaVersion": 1,
  "files": [
    { "path": "instructions.md", "kind": "instruction", "text": "Answer in two short paragraphs." }
  ]
}
```

`POST /bundles/{bundleId}/versions` takes this object as `payload`, with an optional `parentVersionId`.

## Retry a mutation

For content writes that require an idempotency key, provide an `Idempotency-Key` of 1–128 printable ASCII characters. Retry with the same key and exact request bytes. A different body with that key can return a 409 conflict. Bundle setup, version creation and release writes support retained results. Send `X-Acclimate-Durable-Operation: true` with a UUID idempotency key. Look up a lost write with `GET /operations/{key}?operationPath=...`. To close it, send `POST /operations/{key}/close` with the same `Idempotency-Key` and a JSON body containing `operationPath`. Use the full original API path for `operationPath`.

Release writes take `versionId`, `expectedRevision` as a string (use `"0"` for a new channel), and a nonblank `unevaluatedReason`. On a revision conflict, re-read the channel before submitting a new release.

## Learning

All bundle routes sit under `/v1/workspaces/{ws}/bundles/{b}/learning`.

| Route | Purpose | Right |
| --- | --- | --- |
| `PUT` (root) | Turn learning on or change its settings: channel, `domain` and `benchmark`, task model, judge model, `maxRoundsPerDay` | promote |
| `GET` (root) | Loop status, `waiting` reason, pause reason, split counts, active round, alert state, and `optimizerConfigured` | read |
| `POST /start` | Start learning. Refused with `tasks-required` below the Start floor, and with `optimizer-required` when the service has no optimizer model. | promote |
| `POST /pause`, `/resume`, `/stop` | Pause, resume or stop learning. Resume is refused like Start. | promote |
| `GET /tasks` | List tasks, paged. Filters: `split`, `source`, `admission`, `flagged` | read |
| `POST /tasks` | Create one task | write |
| `PATCH /tasks/{id}` | Edit a task. Bumps the task revision and re-runs admission. | write |
| `DELETE /tasks/{id}` | Retire a task. Rows are kept. | write |
| `POST /tasks/import` | Streamed upload of a spreadsheet, CSV, JSONL or pasted text. Returns an import with counts, and the drafted task cards for a console session. | write |
| `GET /tasks/imports/{id}` | Import status and counts of converted, pending and set-aside source rows | read |
| `POST /tasks/{id}/try` | Run one task on the executor against the channel head. Returns a trial ID. | write |
| `GET /trials/{id}` | A trial's status, gateway log, output and verdict | read |
| `GET /held-out-tasks/export` | Download the held-out tasks | console session only |
| `GET /rounds`, `GET /rounds/{id}` | Round timeline, and one round with its candidates, diffs, diagnoses and evolve results | read |
| `POST /rollback` | Move the channel back to the version a named round replaced. The removed version is blocked from adoption. | promote |
| `GET /blocked-versions` | Versions blocked from adoption after a rollback or revert | read |
| `DELETE /blocked-versions/{digest}` | Unblock a version | promote |
| `GET /usage` | Rounds, rollouts and tokens per day | read |
| `POST /outcomes` | A production outcome from `job.expect()` | write |
| `GET /memory` | Improvement memory at a revision | read |

The workspace model provider is at `GET` and `PUT /v1/workspaces/{ws}/model-provider`. It holds an OpenAI-compatible base URL, the key and the allowed models. `PUT` needs a signed-in administrator. The key is write-only: `GET` returns whether one is set and the executor's verification result, never the key.

A signed-in caller needs the administrator role wherever a machine token needs `promote`.
