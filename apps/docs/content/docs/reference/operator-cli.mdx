---
title: Operator CLI
description: Inspect proposals and comparison evidence, and read source channel history.
---

Use the operator CLI to read evidence and request standalone proposals. It ships in the TypeScript SDK as `acclimate-operator`, so it runs wherever the SDK is installed. Set `ACCLIMATE_URL`, `ACCLIMATE_TOKEN`, and `ACCLIMATE_SCOPE` for a scoped principal on a trusted TLS endpoint.

```sh
npm install --offline --ignore-scripts /absolute/path/to/release/acclimate-sdk-0.1.0.tgz
npx acclimate-operator history --workspace WORKSPACE --bundle BUNDLE --channel live --limit 20
npx acclimate-operator review --workspace WORKSPACE --bundle BUNDLE --channel live \
  --comparison COMPARISON --proposal PROPOSAL
```

Run `acclimate-operator --help` for the command list. From an Acclimate checkout, `npm run operator -- COMMAND ...` runs the same CLI.

## Commands

All commands need `--workspace` and `--bundle`. Channel commands also need `--channel`.

| Command | Command-specific options |
| --- | --- |
| `request-proposal` | `--parent`, repeatable `--path`, `--hypothesis`, repeatable `--evidence`. |
| `proposal` | `--id` for the proposal. |
| `review` | `--comparison`, plus optional `--proposal` to verify the proposal binding. |
| `history` | Optional `--limit` and `--before` revision for pagination. |

`review` verifies both immutable payload digests and shows the source revision, file differences, and recorded comparison evidence. The connected worker checks the application policy before rollout.

## Output and retries

The CLI writes JSON to stdout and errors to stderr. Use `--json` for compact JSON. Use `--output PATH` to create a new report file with mode 0600. The existing parent must belong to the current user, have mode 0700 or stricter, and have a symlink-free path.

Supply `--key KEY` to a mutation if you need to retry the same request with the same key. The command generates a fresh key when omitted. Use a new key when changing the request. See [inspect automatic releases and rollbacks](/docs/guides/review-and-release) for the release workflow.
