The `acclimate-sdk` package needs Python 3.11 or later and has no third-party dependencies. File preparation uses POSIX on Linux or macOS. [Install it](/docs/get-started/install) with `pip install acclimate-sdk`, then import it as `acclimate`.

## Naming

Python names are snake_case: method names, keyword arguments, and attributes such as `ApiError.request_id` and `TransportError.service_url`. HTTP request and response dictionaries keep the wire contract's camelCase keys, such as `version["parentVersionId"]`, because they are the JSON the service sends and accepts. The TypedDicts in `acclimate.types` describe them. The root package also exports those types, `AcclimateClient`, `Acclimate`, `Job`, the delivery helpers `prepare_files`, `resolve_and_cache` and `validate_payload`, the `PreparedFiles` and `PreparedDelivery` types, and the receipt helpers `DeliveryReporter` and `BoundDeliveryReporter`.

## Deliver a pinned version to a job

```py
import os
from acclimate import AcclimateClient

client = AcclimateClient(os.environ["ACCLIMATE_URL"], os.environ["ACCLIMATE_TOKEN"], "support-agent")
with client.prepare(workspace_id, bundle_id, channel="stable") as prepared:
    result = run_agent(task, instructions=prepared.instructions, skill_files=prepared.skill_files)
    save_job_result(result, version=prepared.version["version"]["id"], digest=prepared.version["version"]["digest"])
```

The task, IDs, agent call and result storage belong to your application. Pass `version_id=` instead of `channel=` to request an exact version. For background work, keep the prepared object and call `cleanup()` after the job stops and its result is saved.

| Attribute of the prepared job | Contents |
| --- | --- |
| `version` | The verified version: its metadata in `version["version"]`, including `id` and `digest`, the verified `payload`, and resolution details. `version["stale"]` is true when the content came from the offline cache. |
| `instructions` | The instruction files joined into one string. |
| `skill_files`, `files` | Staged skill files, and every staged file, with `path`, `kind` and `absolutePath`. |
| `directory` | The private job directory. |
| `report_started()` | Reports the job's start when the client has a `DeliveryReporter`. |

The cache defaults to `~/.cache/acclimate/python`. Set `cache_dir` to change it and `destination` to choose the job directory. Keep a separate cache directory for each SDK language.

Every channel job confirms its release online. For an exact version, allow verified cache fallback after a transport failure or HTTP 503 with its pinned version ID.

```py
client.prepare(workspace_id, bundle_id, version_id=pinned, offline={"pinned_version_id": pinned})
```

A denial, a missing resource or an integrity failure never falls back. `resolve_and_cache(client, workspace_id, bundle_id, cache_dir=..., ...)` and `prepare_files(version, destination)` run the two steps separately. `validate_payload(payload)` checks a bundle payload without contacting the service.

## Client

`AcclimateClient(base_url, token, scope, *, retries=2, timeout=30, max_payload_bytes=1048576, max_json_response_bytes=4194304, connection_id=None)`

`scope` is a stable name for the authenticated application. It namespaces the cache and must never be a token. Set `connection_id` to the connection UUID when the application reads content for a connection. The client is synchronous, rejects redirects so the token never leaves the configured origin, and bounds every response.

Content writes such as uploading a version take a required idempotency key of 1–128 printable ASCII characters. `enroll_learning_loop` and the pause, resume and stop calls take optional keys. Outcome reporting defaults to the outcome ID as its key. Retry a lost write with the same key and the same request. Workspace, bundle, channel and connection listings take `cursor=` and `limit=` keyword arguments and return `{"items": [...], "nextCursor": ...}`; pass `nextCursor` back as `cursor` to read the next page.

The Python client uses snake_case equivalents of the shared TypeScript client methods.

| Area | Methods |
| --- | --- |
| Workspaces and bundles | `list_workspaces`, `list_bundles`, `create_bundle`, `create_bundle_setup` |
| Versions | `create_version`, `get_version`, `get_payload` |
| Channels and releases | `list_channels`, `resolve_channel`, `inspect_source`, `list_releases`, `create_release` |
| Connections and receipts | `create_connection`, `list_connections`, `create_connection_credential`, `revoke_connection`, `revoke_connection_credential`, `report_delivery_receipt`, `list_delivery_receipts`, `list_connection_observations` |
| Retained operations | `get_operation`, `close_operation` |
| Other | `health`, `prepare` |


Differences from the TypeScript client:

- `resolve_channel` returns a `(resolution, etag, not_modified)` tuple.
- The TypeScript client's `sessionToken` and `fetch` options have no Python equivalent. The session token is only for the console's own server.

## Errors

| Exception | Raised when |
| --- | --- |
| `acclimate.AcclimateError` | The base class of every error below. It has a stable `code`. |
| `acclimate.UsageError` | An argument is invalid. A `ValueError` subclass with the argument's name in `field`. |
| `acclimate.ApiError` | The service returns an error. It has `status`, `code`, `request_id` and optional `details`. Quote `request_id` when you report a problem. |
| `acclimate.TransportError` | The request fails before a response arrives. |
| `acclimate.DeliveryError` | Delivery finds a malformed response, cache entry or payload. It has a `code`. |

## Reporters

`DeliveryReporter(client, workspace_id, connection_id, *, max_queue=100)` reports delivery stages for a connection from a background thread. Pass it to `client.prepare(..., reporter=reporter)` and call `prepared.report_started()` when the job starts. Report failures never block delivery. Call `wait(timeout)` and then `close(timeout)` before a short-lived process exits.

## Learning

Use `job.expect(expected, input=task, output=response)` with a write token to submit a production outcome. Pass `grading="exact"` or `grading="criteria"` to choose how the expected answer is graded; any other value raises `UsageError`. Without it, a non-string answer or a string of at most 80 characters on one line is compared exactly, and a longer answer is judged against criteria the judge model drafts from it. [Import shapes](/docs/guides/learning-loop#import-shapes)

The client exposes `enroll_learning_loop`, `get_learning_loop`, `pause_learning_loop`, `resume_learning_loop`, `stop_learning_loop`, `list_learning_rounds`, `get_learning_round`, `get_learning_memory`, `start_learning_loop`, `list_learning_tasks`, `create_learning_task`, `edit_learning_task`, `retire_learning_task`, `export_held_out_tasks`, `try_learning_task`, `get_learning_trial`, `get_learning_import`, `import_learning_tasks`, `list_blocked_learning_versions`, `unblock_learning_version`, `get_learning_usage`, `rollback_learning_round`, `get_model_provider`, `set_model_provider`, `report_learning_outcome`. The Python client has no methods yet for the task confirmation, recheck and import-list routes, and `list_learning_tasks` has no `confirmed` filter; call those over [HTTP](/docs/reference/http-api#learning).

Use `acclimate pull --config /absolute/path/pull.json --bundle ID --channel stable --out payload.json` to save a released payload. Use a new output path. The config is an owner-only JSON file inside an owner-only directory with `schemaVersion` set to 1, `serviceUrl`, `workspaceId`, `scope` and an absolute `cacheDir`. Supply the read credential through `ACCLIMATE_TOKEN` or the private config’s `token` field.
