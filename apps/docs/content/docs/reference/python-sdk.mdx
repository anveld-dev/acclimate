The `acclimate-sdk` package needs Python 3.11 or later on Linux or macOS and has no third-party dependencies. [Install it](/docs/get-started/install) with `pip install acclimate-sdk`, then import it as `acclimate`.

## Naming

Python names are snake_case: method names, keyword arguments, and attributes such as `ApiError.request_id` and `ExecuteInput.case_id`. HTTP request and response dictionaries keep the wire contract's camelCase keys, such as `version["parentVersionId"]`, because they are the JSON the service sends and accepts. The TypedDicts in `acclimate.types` describe them.

## Deliver a pinned version to a job

```py
import os
from acclimate import AcclimateClient

client = AcclimateClient(os.environ["ACCLIMATE_URL"], os.environ["ACCLIMATE_TOKEN"], "support-agent")
with client.prepare(workspace_id, bundle_id, channel="stable") as prepared:
    result = run_agent(task, instructions=prepared.instructions, skill_files=prepared.skill_files)
    save_job_result(result, version=prepared.version["version"]["id"], digest=prepared.version["version"]["digest"])
```

The task, IDs, agent call and result storage belong to your application. Pass `version_id=` instead of `channel=` to request an exact version. For background work, keep the prepared object and call `cleanup()` after the job stops and its result is saved.

| Attribute of the prepared job | Contents |
| --- | --- |
| `version` | The verified version: its metadata in `version["version"]`, including `id` and `digest`, the verified `payload`, and resolution details. `version["stale"]` is true when the content came from the offline cache. |
| `instructions` | The instruction files joined into one string. |
| `skill_files`, `files` | Staged skill files, and every staged file, with `path`, `kind` and `absolutePath`. |
| `directory` | The private job directory. |
| `report_started()` | Reports the job's start when the client has a `DeliveryReporter`. |

The cache defaults to `~/.cache/acclimate/python`. Set `cache_dir` to change it and `destination` to choose the job directory. Keep a separate cache directory for each SDK language.

Every channel job confirms its release online. For an exact version, allow verified cache fallback after a transport failure or HTTP 503 with its pinned version ID.

```py
client.prepare(workspace_id, bundle_id, version_id=pinned, offline={"pinned_version_id": pinned})
```

A denial, a missing resource or an integrity failure never falls back. `resolve_and_cache(client, workspace_id, bundle_id, cache_dir=..., ...)` and `prepare_files(version, destination)` run the two steps separately. `validate_payload(payload)` checks a bundle payload without contacting the service.

## Client

`AcclimateClient(base_url, token, scope, *, retries=2, timeout=30, max_payload_bytes=1048576, max_json_response_bytes=4194304, connection_id=None)`

`scope` is a stable name for the authenticated application. It namespaces the cache and must never be a token. Set `connection_id` to the connection UUID when the application reads content for a connection. The client is synchronous, rejects redirects so the token never leaves the configured origin, and bounds every response.

Every mutation takes an explicit idempotency key of 1–128 printable ASCII characters. Retry a lost write with the same key and the same request. Listing methods take `cursor=` and `limit=` keyword arguments and return `{"items": [...], "nextCursor": ...}`; pass `nextCursor` back as `cursor` to read the next page.

The Python client uses snake_case equivalents of the shared TypeScript client methods.

| Area | Methods |
| --- | --- |
| Workspaces and bundles | `list_workspaces`, `get_principal`, `list_bundles`, `create_bundle`, `create_bundle_setup` |
| Versions | `create_version`, `get_version`, `get_payload` |
| Channels and releases | `list_channels`, `resolve_channel`, `inspect_source`, `list_releases`, `create_release` |
| Connections and receipts | `create_connection`, `list_connections`, `create_connection_credential`, `revoke_connection`, `revoke_connection_credential`, `report_delivery_receipt`, `list_delivery_receipts`, `list_connection_observations` |
| Retained operations | `get_operation`, `close_operation` |
| Other | `health`, `prepare` |

For the local evaluator and payload tools in the Python SDK, see the [evaluator CLI reference](/docs/reference/evaluator-cli).

Differences from the TypeScript client:

- `resolve_channel` returns a `(resolution, etag, not_modified)` tuple.
- The TypeScript client's `sessionToken` and `fetch` options have no Python equivalent. The session token is only for the console's own server.

## Errors

| Exception | Raised when |
| --- | --- |
| `acclimate.AcclimateError` | The base class of every error below. It has a stable `code`. |
| `acclimate.UsageError` | An argument is invalid. A `ValueError` subclass with the argument's name in `field`. |
| `acclimate.ApiError` | The service returns an error. It has `status`, `code`, `request_id` and optional `details`. Quote `request_id` when you report a problem. |
| `acclimate.TransportError` | The request fails before a response arrives. |
| `acclimate.DeliveryError` | Delivery finds a malformed response, cache entry or payload. It has a `code`. |
| `acclimate.evaluation.EvaluationError` | An evaluation step fails. It has `code`, `phase`, `next_action`, `execution_state` and a printable `diagnostic` dictionary. `acclimate.evaluation.ERROR_CODES` and `EXIT_CODES` list every code and the CLI exit status; see [error codes](/docs/reference/error-codes). |
| `acclimate.evaluation.DefinitionError` | `define_evaluation` rejects an argument. `field` names it, such as `cases[1].case_id`. Code `definition.invalid`. |
| `acclimate.evaluation.OutputValidationError` | A callback returned a value that is not plain JSON, or unknown `usage` keys. Code `output.invalid`. |
| `acclimate.evaluation.EvaluationUsageError` | The evaluator command line is invalid. Code `usage.*`. |

## Reporters

`DeliveryReporter(client, workspace_id, connection_id, *, max_queue=100)` reports delivery stages for a connection from a background thread. Pass it to `client.prepare(..., reporter=reporter)` and call `prepared.report_started()` when the job starts. Report failures never block delivery. Call `wait(timeout)` and then `close(timeout)` before a short-lived process exits.

`EvaluationProgressReporter(client, *, workspace_id, bundle_id, request_id, attempt_id)` reports optional progress for a running evaluation with `report(sequence=..., phase=..., completed=..., total=...)`. It returns `False` instead of raising when a report fails.

## Learning

Create `acclimate_loop.py` next to a JSON or JSONL file of examples. Each example has
`input` and `expected`, and may supply a stable `caseId`.

```python
import json
from acclimate.learning import define_loop, exact, openai

loop = define_loop(
    bundle="support-agent",
    channel="stable",
    agent=openai("gpt-6.2-sol", parse=json.loads),
    cases="cases.jsonl",
    grade=exact("action"),
)
```

Set `ACCLIMATE_URL`, `ACCLIMATE_WORKSPACE`, and `ACCLIMATE_TOKEN` for the
evaluator. The token needs `evaluate` access and must belong to the enrolled
app principal. The CLI reads the principal ID from the service. You can also
set `ACCLIMATE_APP_PRINCIPAL` explicitly (for a machine token,
`machine:<name>`). Enrollment requires `promote` access. If the service
requires a different principal for enrollment, set `ACCLIMATE_ENROLL_TOKEN`
to a separate token with `promote` access. The channel needs an existing release.

```sh
python -m acclimate learn
python -m acclimate learn --config ./acclimate_loop.py --once
```

The command resolves the bundle by name, reconciles enrollment, syncs evolve
cases, and prints round progress. `--once` exits after a completed round.
Case paths are relative to the loop file. The setting defaults to the bundle
name as `domain`, the case filename as `benchmark`, and the agent model as
`policyModel`. Pass `policy_model`, `domain` or `benchmark` to override those
defaults.

The default split assigns a case to held-out when the unsigned big-endian
SHA-256 digest of its UTF-8 case ID is below `2**255`. A missing case ID
defaults to the SHA-256 hex of the canonical JSON input. Keep examples in both
splits. The command uploads evolve cases and keeps held-out inputs and
expectations local. Removing an evolve example retires it. Give edited examples
a new case ID because the service treats case content as immutable. Production
outcomes survive file sync.

`openai(model, base_url=None, api_key=None, effort=None, parse=None, render=None)` uses an OpenAI-compatible Chat Completions endpoint. It reads `OPENAI_BASE_URL` (default `https://api.openai.com/v1`) and `OPENAI_API_KEY` when the corresponding options are omitted. `render(version)` receives the verified version and returns system text. `parse(text)` transforms the assistant text before grading. Both callbacks are synchronous. HTTP failures raise `OpenAIHttpError` with `.status` and a key-redacted `.trace`. [CLIProxyAPI setup](/docs/guides/learning-loop#use-codex-through-cliproxyapi)

For custom execution, pass `policy_model` and implement `execute(version, input, rollout)` as a synchronous function that
returns output or `(output, trace)`. Rollout indexes run from zero through four.
Use `exact()` for whole-output JSON equality or `exact("action")` to compare
the top-level `action` field to the expected value. Use `tests(command, cwd=None)`
to run a shell command against `output.json` in a temporary directory, with an
optional copy of the fixture directory at `cwd`. Exit status zero scores 1 and
any other exit status scores 0. A custom `grade(output, expected)` can return
a score between 0 and 1, or a dict containing `score` and `passed`.

### Record production outcomes

```python
from acclimate import Acclimate

acclimate = Acclimate.from_env()
job = acclimate.job("support-agent", channel="stable", input=ticket)
with job.prepare() as prepared:
    run_my_production_agent(prepared)
receipt = job.expect("refund")
```

`Acclimate(url, workspace, token, cache_dir=...)` accepts explicit connection
settings. The outcome expectation uses the same shape as the case file, such
as `"refund"` with `exact("action")` or `{"action": "refund"}` with `exact()`.
`job.version` exposes the verified version pinned when the job was
created. `job.prepare(destination=None)` stages that same version using the
delivery context manager. Use `job.expect(expected, input=...)` to override
the job input. Retry the same outcome on the same job to reuse `job.outcome_id`
and its server-side receipt.

### Learning client reference

Import wire types such as `LearningLoopRequest`, `LearningLoop`, `LearningRoundSummary`, `LearningRound`, `LearningCandidate`, `LearningSelection`, `LearningMemory`, `LearningEvaluation` and `LearningWork` from `acclimate.types`. The client methods take the workspace ID and bundle ID first. JSON keys follow the [HTTP contract](/docs/reference/http-api#learning-loop).

| Task | Client methods |
| --- | --- |
| Enroll and control | `enroll_learning_loop`, `pause_learning_loop`, `resume_learning_loop`, `stop_learning_loop` |
| Inspect | `get_learning_loop`, `list_learning_rounds`, `get_learning_round`, `get_learning_memory` |
| Manage evolve cases and report outcomes | `list_learning_evolve_cases`, `add_learning_evolve_cases`, `report_learning_outcome` |
| Serve evaluation work | `get_learning_work`, `start_learning_evaluation`, `report_learning_evaluation` |

`acclimate.learning.held_out_digest(cases)` computes the enrollment digest
from the evaluator's private cases. To run evaluations directly, call
`acclimate.learning.serve_learning_loop(client, workspace_id, bundle_id, execute=..., grade=..., held_out=...)`.
The runner keeps a private local journal so restarts can reuse completed
rollouts and skip cases the service already accepted. Supply `journal_dir`
to override the default at `~/.local/state/acclimate/python-learning`.

`get_learning_round` returns candidates and the selector decision. `get_learning_memory` returns the latest improvement memory or a specific revision when you supply `revision`. Read memory as a workspace reader other than the app principal.
