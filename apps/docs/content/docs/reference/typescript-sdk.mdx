Install `@acclimate/sdk` with Node.js 22.22 or later. See [install the SDKs](/docs/get-started/install). Import only the entry points below; other paths inside the package are private and can change in any release.

## Deliver a pinned version

Construct `AcclimateClient` with `baseUrl`, `token`, and a stable `scope` that identifies the authenticated application. Use the connection UUID as `connectionId` when resolving for a connection. Call `client.prepare` with `workspaceId`, `bundleId`, and exactly one of `channel` or `versionId`. It returns the verified `version` (its metadata is `version.version`), `directory`, `instructions`, `skillFiles`, `reportStarted()`, and `cleanup()`.

The default preparation cache is `~/.cache/acclimate/typescript`. Set `cacheDir` to override it and `destination` to select an application-owned staging directory. Start jobs with an online resolution by default. For a bounded cached channel fallback, pass `offline: { maxAgeMs: ... }`. For exact version fallback, pass `offline: { pinnedVersionId: ... }`. The Python SDK takes the same policy as `offline={"max_age_ms": ...}` or `offline={"pinned_version_id": ...}`. Access denial and integrity errors fail preparation.

Use `resolveAndCache` when you want a verified version for a native plugin or your own preparation. See [deliver content to jobs](/docs/guides/deliver-content) for a complete job flow and [configuration](/docs/reference/configuration) for app and worker settings.

## Errors

| Error | Thrown when |
| --- | --- |
| `AcclimateError` | The base class of every error the SDK throws on purpose. It has a typed `code`. |
| `AcclimateUsageError` | An argument is invalid. `field` names it. |
| `TransportError` | A network failure or timeout. It keeps the native error as `cause` and the service origin as `serviceUrl`. |
| `ApiError` | The service returns an error. It has `status`, `code`, `requestId` and optional `details`. |
| `DeliveryError` | Delivery finds a malformed response, cache entry or payload. |
| `TaskExecutionError`, `InfrastructureError` | Thrown from execution callbacks to mark a task failure or an infrastructure failure. |
| `EvaluationError` | An evaluation step fails. It has a stable `code` and a printable diagnostic. See [error codes](/docs/reference/error-codes). |
| `DefinitionError`, `OutputValidationError`, `AppSetupError`, `EvaluationUsageError` | `defineEvaluation` rejects a `field` such as `cases[1].caseId`, a callback returns non-JSON output, the application module is invalid, or the command line is invalid. |
| `LocalRunError` | A local run's payload, `--out` folder or `--live` flag is invalid. |
| `ExecutionUncertainError`, `CallbackCancelled` | Thrown from your callbacks: when external work might still be running, or after the callback stops for cooperative cancellation. |

[Versioning and compatibility](/docs/reference/versioning) covers which SDK versions work with which service versions and how deprecated names are removed.

## Learning

Import loop wire types such as `LearningLoopRequest`, `LearningLoop`, `LearningRoundSummary`, `LearningRound`, `LearningCandidate`, `LearningSelection`, `LearningMemory`, `LearningEvaluation` and `LearningWork` from `@acclimate/sdk`.

| Task | `AcclimateClient` methods |
| --- | --- |
| Enroll and control | `enrollLearningLoop`, `pauseLearningLoop`, `resumeLearningLoop`, `stopLearningLoop` |
| Inspect | `getLearningLoop`, `listLearningRounds`, `getLearningRound`, `getLearningMemory` |
| Add evolve cases or outcomes | `addLearningEvolveCases`, `reportLearningOutcome` |
| Serve evaluation work | `getLearningWork`, `startLearningEvaluation`, `reportLearningEvaluation` |

Each method takes the workspace ID and bundle ID first. See the [HTTP contract](/docs/reference/http-api#learning-loop) for the request shapes.

`@acclimate/sdk/learning` exports `serveLearningLoop`, `heldOutDigest`, `addEvolveCases`, `createLearningOutcomeReporter` and the `LearningLoopApp` and `LearningLoopOptions` types. The `acclimate-learning` bin serves an enrolled bundle. See the [learning evaluator CLI](/docs/reference/evaluator-cli#learning-evaluator).

`getLearningRound` returns candidates and the selector decision. `getLearningMemory` returns the latest improvement memory or a specific revision when you supply `revision`. Read memory as a workspace reader other than the app principal.
