Install `@acclimate/sdk` with Node.js 22.22 or later. See [install the SDKs](/docs/get-started/install). Import only the entry points below; other paths inside the package are private and can change in any release.

The types match [`contracts/openapi.json`](/docs/reference/http-api).

## Commands

| Command | Use |
| --- | --- |
| `acclimate-eval` | The [evaluator CLI](/docs/reference/evaluator-cli). It loads `application.mjs` or `application.mts` from the current directory. |
| `acclimate-learning` | Runs the connected learning worker. See [connected learning](/docs/guides/connected-learning). |
| `acclimate-operator` | Inspects comparisons and recorded release history. See the [operator CLI](/docs/reference/operator-cli). |

## Start a job with its connection’s release

Construct `AcclimateClient` with `baseUrl`, `token`, a stable cache `scope`, and the enrolled connection UUID as `connectionId`. Call `client.prepare({ workspaceId, bundleId, channel })` once per new job. The job keeps its verified version and staged files until cleanup.

The default cache is `~/.cache/acclimate/typescript`. Set `cacheDir` to change its location and `destination` to choose the staging directory. Every new job resolves the enrolled connection online. Cached verified file contents can be reused once the service confirms the version.

Use `resolveAndCache` when you want a verified version for a native plugin or your own preparation. See [deliver content to jobs](/docs/guides/deliver-content) for a complete job flow and [configuration](/docs/reference/configuration) for app and worker settings.

## Errors

| Error | Thrown when |
| --- | --- |
| `AcclimateError` | The base class of every error the SDK throws on purpose. It has a typed `code`. |
| `AcclimateUsageError` | An argument is invalid. `field` names it. |
| `TransportError` | A network failure or timeout. It keeps the native error as `cause` and the service origin as `serviceUrl`. |
| `ApiError` | The service returns an error. It has `status`, `code`, `requestId` and optional `details`. |
| `DeliveryError` | Delivery finds a malformed response, cache entry or payload. |
| `TaskExecutionError`, `InfrastructureError` | Thrown from your `compare` callbacks to mark a task failure or an infrastructure failure. |
| `EvaluationError` | An evaluation step fails. It has a stable `code` and a printable diagnostic. See [error codes](/docs/reference/error-codes). |
| `DefinitionError`, `OutputValidationError`, `AppSetupError`, `EvaluationUsageError` | `defineEvaluation` rejects a `field` such as `cases[1].caseId`, a callback returns non-JSON output, the application module is invalid, or the command line is invalid. |
| `LocalRunError` | A local run's payload, `--out` folder or `--live` flag is invalid. |
| `ExecutionUncertainError`, `CallbackCancelled` | Thrown from your callbacks: when external work might still be running, or after the callback stops for cooperative cancellation. |
| `EvaluationConfigurationError`, `PolicyError`, `AnalysisError` | A descriptor, handoff, quality policy or analysis input is invalid. |

[Versioning and compatibility](/docs/reference/versioning) covers which SDK versions work with which service versions and how deprecated names are removed.
