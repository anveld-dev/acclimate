Install `@acclimate/sdk` with Node.js 22.22 or later. See [install the SDKs](/docs/get-started/install). Import only the entry points below; other paths inside the package are private and can change in any release.

## Entry points

| Entry point | Runtime exports |
| --- | --- |
| `@acclimate/sdk` | `createAcclimate`, `AcclimateClient`, `ApiError`, `resolveAndCache`, `defaultCacheDir`, `prepareFiles`, `verifyPayloadBytes`, `validatePayload`, `DeliveryError`, `createReceiptReporter`, `TaskExecutionError`, `InfrastructureError`, `compatibilityIssues`, `assertCompatible`, `AcclimateError`, `AcclimateUsageError`, `TransportError` |
| `@acclimate/sdk/validation` | `validatePayload`, `DeliveryError`, `compatibilityIssues`, `assertCompatible` |
| `@acclimate/sdk/native-files` | `prepareNativeFiles`, `nativeSource` and `transcriptTail`, for plugin authors. |

The root entry also exports every wire type, such as `Bundle`, `VersionMetadata`, `Release` and `Page`, plus option types such as `ClientOptions`, `CachePolicy`, `OfflinePolicy` and `PrepareDeliveryOptions`. The types match [`contracts/openapi.json`](/docs/reference/http-api).

## Commands

The `acclimate` executable provides one command. Use `acclimate pull --config /absolute/path/pull.json --bundle ID --channel stable --out payload.json` to save a released payload. Use a new output path. The config is an owner-only JSON file inside an owner-only directory with `schemaVersion` set to 1, `serviceUrl`, `workspaceId`, `scope` and an absolute `cacheDir`. Supply the read credential through `ACCLIMATE_TOKEN` or the private config’s `token` field. Use `tokenFile` for an absolute path to a separate owner-only credential file.

## Deliver a pinned version

`createAcclimate(options?)` reads `ACCLIMATE_URL`, `ACCLIMATE_WORKSPACE` and `ACCLIMATE_TOKEN` by default. Its `job(bundleName, { channel, input?, outcomeId? })` resolves and verifies the release. Use `versionId` in place of `channel` to recreate a pinned job. The job exposes the verified `version`, an `outcomeId`, `prepare(nativePrepare)` or `prepare(destination, options?)`, and `expect(expected, { input, output, grading }?)`. The first valid `expect` binds the input and expected value. Subsequent calls reuse the same ID and body. [Production outcomes](/docs/guides/learning-loop#report-a-production-outcome)

Construct `AcclimateClient` with `baseUrl`, `token`, and a stable `scope` that identifies the authenticated application. Use the connection UUID as `connectionId` when resolving for a connection. Call `client.prepare` with `workspaceId`, `bundleId`, and exactly one of `channel` or `versionId`. It returns the verified `version` (its metadata is `version.version`), `directory`, `instructions`, `skillFiles`, `reportStarted()`, and `cleanup()`.

Use `client.inspectSource(workspaceId, bundleId, channel)` to read the latest release from source history.

The default preparation cache is `~/.cache/acclimate/typescript`. Set `cacheDir` to override it and `destination` to select an application-owned staging directory. Each channel job confirms its release online. For an exact version, pass `offline: { pinnedVersionId: ... }` to permit verified cache fallback after a transport failure or HTTP 503. Python uses `offline={"pinned_version_id": ...}`. Access denial and integrity errors fail preparation.

Use `resolveAndCache` when you want a verified version for a native plugin or your own preparation. See [deliver content to jobs](/docs/guides/deliver-content) for a complete job flow and [configuration](/docs/reference/configuration) for app and worker settings.

## Errors

| Error | Thrown when |
| --- | --- |
| `AcclimateError` | The base class of every error the SDK throws on purpose. It has a typed `code`. |
| `AcclimateUsageError` | An argument is invalid. `field` names it. |
| `TransportError` | A network failure or timeout. It keeps the native error as `cause` and the service origin as `serviceUrl`. |
| `ApiError` | The service returns an error. It has `status`, `code`, `requestId` and optional `details`. |
| `DeliveryError` | Delivery finds a malformed response, cache entry or payload. |
| `TaskExecutionError`, `InfrastructureError` | Thrown from execution callbacks to mark a task failure or an infrastructure failure. |

## Production outcomes

An application with workspace write access can call `job.expect(expected, { input, output, grading })` after a production job. The SDK sends the pinned version and digest. The service assigns the task’s split and runs admission. `grading` is `'exact'` or `'criteria'`, and any other value throws `AcclimateUsageError`. Without it, a non-string answer or a string of at most 80 characters on one line is compared exactly, and a longer answer is judged against criteria the judge model drafts from it. [Import shapes](/docs/guides/learning-loop#import-shapes)

`AcclimateClient` also has `confirmLearningTasks(workspaceId, bundleId, taskIds)`, `recheckLearningTask(workspaceId, bundleId, id)`, `recheckLearningTasks(workspaceId, bundleId, taskIds?)` and `listLearningImports(workspaceId, bundleId)`, and `listLearningTasks` takes a `confirmed` filter. The wire types `LearningGrading`, `LearningFailureCause`, `LearningTaskConfirmation`, `LearningTaskRecheck` and `LearningImportSummary` describe them.
