Setup needs readable code/copy and real credential boundaries; administration retains exact identity and consequence review.
- **Closed and secondary states:** default quiet layout must still have understandable open file/actions menus, hover/focus states, tooltips as secondary help, disclosures, modal forms/decisions, local validation, read-only/disabled and persistent uncertain-operation feedback. A board cannot certify these interaction states.

Reusable installed Button/Input/NativeSelect/Table/Disclosure/Dialog/Popover/DropdownMenu primitives remain the implementation starting point. The new task may change desktop composition; it does not authorize invented routes/features/data or losing full frozen release facts. The preclarification ban on a persistent inspector is superseded: if a new board earns a real workflow benefit, assess its width and state cost rather than reject it by category.
