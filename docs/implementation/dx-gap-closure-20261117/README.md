Python publishes matching modules and explicit progress/root domain exports. The evaluation starter includes installed-only analysis programs and their guide.

Progress is an app observation, never a lease, liveness proof, termination confirmation or replay permission. Named components are app assertions bound to trusted comparison identities, not new execution attestation. Intervals describe repeated execution on the declared fixed task inventory under the caller's assumptions; they do not infer population/model quality or gate promotion. Revision hashes bind the artifacts the app explicitly supplies; they do not discover or attest undeclared code/environment.
