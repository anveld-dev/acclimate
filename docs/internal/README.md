# Internal records

These documents recorded decisions while the service was built in parallel workstreams. They describe file ownership, rollout order and earlier route names. They are not consumer contracts and are not kept current.

| File | Record |
| --- | --- |
| [contracts/IMPLEMENTATION.md](contracts/IMPLEMENTATION.md) | The original R0 implementation contract. |
| [contracts/ROADMAP-ADDITIONS.md](contracts/ROADMAP-ADDITIONS.md) | The release-history addition to R0. |
| [contracts/remediation.md](contracts/remediation.md) | The remediation contract freeze. |
| [contracts/dx-evaluation.md](contracts/dx-evaluation.md) | The installed evaluator and review contract. |

For the current HTTP contract, use [`contracts/openapi.json`](../../contracts/openapi.json).
