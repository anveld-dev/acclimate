# Earlier runtime-platform proposal

**Archived and superseded.** The [current design](../../design/README.md) describes a small service for improving and delivering harness files. The application owns agent execution.

The earlier proposal included a worker fleet, sandbox backend, model/tool gateways, effect recovery, plugin process RPC, and a deployment controller. Those are not current requirements. The Markdown snapshots below preserve the reasoning and source references; they are not in the main site search.
