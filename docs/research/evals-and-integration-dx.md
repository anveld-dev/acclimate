# Acclimate developer experience review

Eight simulated developers reviewed commit `8297b9c` on November 17, 2026. The highest-risk moments came when a developer followed a working example, changed it for their application, and trusted the next green result. A local demo could call a live adapter, a budget check could pass on invented zeros, and a PR check could grade a file unrelated to the PR.

The offline trial has since been removed. The installed SDK now runs a developer's own agent and grader, shows paired scores and preserves the original work on retry. The CI wrapper binds a comparison to the requested Git commit. [Current SDK walkthrough](../getting-started.md) · [CI integration](../../examples/ci/README.md)

The reviewers subsequently retried the packaged SDK. [Findings from the installed SDK retest](installed-sdk-dx-retest.md)

## Findings by developer role

### First-time adopter

The shipped payment fixture makes the concept legible in one command. The first surprise comes when trying to learn from a neutral change. Making the candidate identical to the baseline caused Python to raise an assertion before printing either score. The trial owns a second copy of the cases and grading logic. Put demo expectations in tests and have the editable path show what each version did on the developer's actual cases. [Trial](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/examples/evaluation-starter/trial.py) · [Installed evaluator](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/examples/evaluation-starter/acclimate_eval.py)

### Python agent engineer

The dependency-free wheel installed in a fresh Python 3.11 environment and completed a paired run through a local fixture service. An existing coroutine-based agent hit a different path. Passing an `async def` executor to the public definition raised `config.schema`. The asyncio example moves the synchronous runner onto a worker thread. A copyable example that calls an actual coroutine-based agent and retains cancellation ownership, plus an error pointing to it, would shorten this integration. The starter's handling of usage is the more consequential fix for production adoption. [Callback validation](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/python/acclimate/evaluation.py) · [Async example](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/examples/evaluation-starter/async_eval.py)

### Evaluation engineer

The Python runner accepted runtime metadata declaring TypeScript's `seeded-balanced-v1` schedule, then ran the parent first on all four repetitions of a local test. If a shared tool cache warms on first use, the candidate can benefit on every pair. Reserve scheduler metadata in Python immediately. Support the balanced schedule if Python apps need it, and test that the recorded order matches the callbacks. Equal weighting across distinct cases and explicit partial coverage are worth preserving. [Python runner](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/python/acclimate/evaluation.py) · [TypeScript definition](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/packages/sdk/src/evaluation/definition.ts) · [Arm scheduling](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/packages/sdk/src/evaluation/collection.ts) · [Scorecard](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/apps/console/src/components/evaluation-scorecard.tsx)

### TypeScript tool-loop developer

A tool result carrying `observedAt: new Date()` compiled under strict TypeScript 5.9.3. The durable evaluator rejected the output on both arms with `output_invalid`, and the grader never ran. Give adapters a typed JSON serialization boundary and a local validation error that identifies the field and suggests an ISO string. The local trial also passed after the reviewer made the compiled TypeScript agent throw unconditionally. It imports a separate JavaScript agent. A local run of the installed definition would catch both integration errors before a service-backed request. [Result type](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/packages/sdk/src/evaluation/types.ts) · [Runtime validation](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/packages/sdk/src/evaluation/runner.ts) · [Typed entry point](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/examples/evaluation-starter/typescript/acclimate-eval.ts.template) · [Trial imports](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/examples/evaluation-starter/trial.mjs)

### Console-first prompt developer

After creating a request with the bundled payment preset, the prominent command runs an installed Node starter. The preset expects `payment-retry` with six pairs, while the starter declares `installed-payment-starter` with two. The matching checkout command is tucked into a disclosure. Put the matching command beside the handoff and offer both Node and Python for custom evaluators. When the check finishes, show the policy result bound to that comparison, or give the reviewer the exact command to obtain it. The scorecard already communicates which cases have usable grades. [Request card and commands](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/apps/console/src/components/improvement-workspace.tsx) · [Bundled presets](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/apps/console/src/lib/evaluation-presets.ts) · [Installed starter](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/examples/evaluation-starter/acclimate-eval.mjs) · [Scorecard](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/apps/console/src/components/evaluation-scorecard.tsx)

### Native coding-agent developer

A local coding-agent fixture changed only a test in its writable workspace. Its in-workspace test passed, the retained solution patch was empty, and the original frozen test still failed. The repository helper retains the explicitly selected result files, which is a useful boundary for sharing patches. A team adapting this example needs a separate grader that applies those files to a clean copy and runs the frozen tests. Flag modified test inputs before cleanup. The supplied demo's known-patch assertion protects that particular fixture. [Writable test run and demo assertion](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/examples/native-repository/worker.mjs) · [Patch retention](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/examples/native-repository/repository-job.mjs)

### CI and release engineer

Once a candidate is correctly identified, a read-only reviewer can check its policy independently. The wrapper collapses two different next actions into exit code 2. Both an execution failure and a complete result with a quality regression produced that exit in controlled runs. A final machine-readable summary should identify execution, policy, and export outcomes so CI can route a broken evaluator to its owner and a behavioral regression to the PR author. [Wrapper](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/examples/ci/ci.sh) · [Policy command](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/packages/sdk/src/evaluation/cli.ts)

### Production agent owner

A customer incident's expected and observed behavior reaches the proposer. The candidate then runs against the installation's registered development and audit suites. A passing round can therefore leave the original ticket unanswered. Offer an optional private reproducer keyed to the originating outcome and show its candidate verdict beside the held-out suite results. The existing binding of field grades to the revision that served a job is worth keeping. [Proposal evidence and evaluation inventory](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/src/connected_learning_worker.rs) · [Field audit procedure](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/docs/evaluator-operations.md)

Recovery also needs a better signal. In a fixture, the connected worker received the same required field replay on three active polls. With its optional callback absent, it emitted zero diagnostics and submitted zero verdicts. The service uses the same terminal reason for a graded regression and a 24-hour timeout. Expose the missing callback and affected outcome when the assignment arrives, and give each terminal condition its own reason. [Worker](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/packages/sdk/src/learning/connected.ts) · [Terminal conditions](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/src/connected_learning/field_requalification.rs)

## Smaller changes that would save debugging time

- Put the most recent recorded case, phase and receipt time in CLI `status` and on the newly created request card. The service stores optional progress observations, while the runbook says remote progress is unavailable. An absent observation should display as unknown. [Operator runbook](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/docs/evaluator-operations.md) · [Progress service](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/src/evaluation_progress.rs) · [Request card](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/apps/console/src/components/improvement-workspace.tsx)
- Make an accepted production outcome searchable by ID before it has an admitted learning round. A support engineer currently sees recent admitted rounds and can see “No rounds recorded” while a correction is waiting. [Service view](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/src/connected_learning.rs) · [Connection view](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/apps/console/src/components/connection-learning.tsx)
- Keep large native patches in private artifacts and pass a digest and bounded summary to the grader. A reviewer retained a 560,089-byte patch whose serialized result crossed the evaluator's 1 MiB output limit. The helper should also forward measured usage and explicit task failure status. [Native result](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/examples/native-repository/repository-job.mjs) · [Evaluator result validation](https://github.com/anveld-dev/acclimate/blob/8297b9ca2c241703c8961ad1ac49ce728b64b333/packages/sdk/src/evaluation/runner.ts)

## Verification scope

The reviewers used the checkout, temporary external consumers, instrumented callbacks, fixture transports and controlled CLI responses. The console reviewer traced rendering and routing in source and ran the starter's descriptor command. The production incident assessment follows the service's request construction and worker behavior. This round used local fixtures throughout. Human usability, hosted CI, production deployment and paid-provider behavior remain unmeasured.
