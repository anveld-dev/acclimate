# Continuous learning architecture

The small durable learner decision is superseded by service-managed connected learning. The two implementations drifted in audit cohorts, policy epochs, retries and outcome handling. The service-managed learner is the shipped operator workflow.

The service schedules work and owns selection and release. The installed evaluator runs private fixtures and replays, then reports the resulting evidence. See the [deployment guide](../../../deploy/README.md#operate-connected-learning), [evaluator operations](../../evaluator-operations.md#serve-connected-learning) and [learning contract](../../../contracts/learning.md#service-managed-connected-learning).
