## Frozen seams

- **Configuration:** add required `ACCLIMATE_OIDC_ISSUER`; retain distinct `ACCLIMATE_LOGIN_TOKEN`, `ACCLIMATE_CONSOLE_TOKEN`, exact `ACCLIMATE_OPERATORS` and scoped `ACCLIMATE_AUTH`. `ACCLIMATE_MODE` / `CONSOLE_MODE` are obsolete and rejected. Console requires HTTPS `CONSOLE_ORIGIN`, OIDC issuer/client settings, authority credentials, explicit internal `CONSOLE_SERVICE_URL` and HTTPS `CONSOLE_PUBLIC_API_URL`. Build needs no runtime secrets.
- **Rust state:** A owns parsed immutable `AccessConfig`; R owns `RuntimeStatus`. C0 adds `access: Arc<AccessConfig>` and `runtime: Arc<RuntimeStatus>` to `AppState` and registers modules/routes. Owners publish constructors/methods before callers land. Explicit test configs use the same validation, not a fake-auth mode.
- **Credential classes:** console transport plus valid session is a browser actor; machine grants without session remain machine actors. Machine/session mixtures are denied. Login authority may carry a prior-session rotation hint, not project authority. Strip supplied trusted identity headers. Typed `invalid_session` is emitted only after valid console transport; bad transport cannot settle logout.
- **Adoption:** `POST /v1/auth/workspace-adoptions` receives `{workspaceId,reason}` through current operator+console transport. Result has `workspaceId,userId,reason,createdAt,alreadyAdopted,currentRole`. Migration 0013 adds immutable project-unique `workspace_adoptions` audit and revokes old browser sessions once. Lock with the existing membership writer order; never regrant on historical retry.
- **Migration/runtime:** retain current lock-protected startup migration and project-row registration for explicit grants, never memberships. GET projects is read-only. `/health` is liveness; `/ready` is bounded DB plus initialized owner/live worker/not-draining status, not progress/provider quality. Withdraw readiness and bound shutdown before guard release.
- **Console:** C publishes one pure validation interface callable by D's wrapper, Vite and built prelisten hook. C/U agree AccessState without local mode, successful verified user and current membership plus separate operator capability; anonymous failure advertises sign-in. C provides adoption through access actions. Pin canonical origin; define accepted Host and strip/ignore spoofable forwarding headers. U/E never expose internal URL or transport credentials.
- **Evaluator:** new `evaluate:app -- --config /absolute/private/config.json --bundleID UUID --requestID UUID --adapter NAME [--live]`. Versioned config contains service URL, project, evaluator principal/token and absolute journal root. No `.local`/state-root/ambient fallback. Default UI copies request/config; any example command is setup-required. Preserve service/principal/journal identity for unfinished attempts and exact resume semantics.
- **Fixtures:** F exports one production service config and optional TLS/OIDC lifecycle. Default real OIDC provider handles discovery/code/JWKS/signature/PKCE/state/nonce through the actual console and TLS proxy. Fixture subjects/certs never enter production configuration. B/F coordinate browser sign-in and role seeding without cookie injection as login proof. Machine tests need no browser.
- **Deployment:** D owns one canonical Compose stack: API, built console, persistent PostgreSQL and TLS proxy; only proxy ports published. Both runtime images required. Existing systemd is labeled API-only. No daemon start, public deploy, registry publication, secret generation/adoption of the user's data incidentally.

## Waves

1. A/R/C publish config/state/probe/startup interfaces while U drafts mode-free UI, E builds explicit runner config, D writes templates and F builds test-only TLS issuer/proxy. C0 wires shared fields/migration; B maps preserved stories and prepares consumers.
2. Integrate authority→console→UI and fixture→qualification. Run narrow real-service/protocol tests. C0 resolves shared compile seams. Generic fixture success is never live-provider evidence.
3. Run complete isolated Rust, package/console/evaluator/operator/Python and model-free qualification; full preserved behavior inventory, real Vite path, native Chrome zoom, actual built/dev fail-before-listen and upgrade preservation. Verify both runtime artifacts and manifests. Docker execution remains separately blocked if unavailable.
4. Update active docs/evidence, retire old bypass entrypoints, preserve private files and real PG data. The old local-operator process cannot be left as the app's supported running path. Real deployment/provider configuration remains explicit input; never substitute a fake login to keep it running.

## Completion

All code/acceptance tasks must actually pass; do not complete based on a partial run or missing DB tests. Preserve all original 141 behaviors / 183 variants, recording additions deliberately. Inspect every failure; retain evidence and classify external gates honestly. Default checks call no models; opted-in live models stay Luna-only. Credentials never appear in logs, prompts or docs.
