## Recommendation

Closer bundle identity and exact channel actions improve scanning in sparse and many-bundle libraries. Honest unused space can remain. Shared typography, tokens and action hierarchy can unify library and editor while their widths differ.

Preserve direct name/channel navigation and noninteractive zero-channel names; never make the entire row a nested click target.

Borrow **C's focused import Dialog** with the persistent file explorer. Preserve real folder/file inputs, preview, errors and confirmation. The image's collision replacement promise is false: existing-path collisions reject the batch. Import changes the browser draft; Save remains separate. Reject **D's hidden frequent file navigator**: its extra source width does not earn the repeated opening cost.

Borrow **F's compact paired evidence geometry**, with truthful inventory state and each arm's output/error access. Reject its literal “Complete inventory” for incomplete evidence and green success framing. **E's sidebar** repeats generation/channel, narrows the table and duplicates outcomes as prose without earning that space.

- Keep available facts only: name, origin, fixed compatibility target and exact channel names. No invented counts, dates, activity or content previews.

- Empty editor/viewer states remain distinct. Creation still offers all four source modes and publishing settings.
- Unresolved creation recovery remains above list/form and blocks another creation. Dirty form and import state must survive presentation changes according to existing guards.
