# Roadmap

The current release supports versioned bundle delivery. Workspaces and connections control access. The SDKs fetch, verify and prepare the released content for application-owned jobs.

A later phase introduces one self-improvement loop per enrolled bundle. Subsequent phases add candidate optimization and improvement memory, then use the same loop in a paper-scale experiment. See the [phased plan](../architecture/self-improvement-memory/README.md#phased-plan).
