title: Deliver content to jobs
description: Prepare a pinned version for each job and stage an existing repository for a native coding agent.
---

Prepare a verified version when your application starts a job. In the console, open the bundle's **App setup** guide for the API URL, workspace ID, bundle ID, channel, and SDK recipe. Use a content-read credential for the connection.

## Prepare the job's content

Set the connection ID on the SDK client and resolve its channel once per new job. Give your agent the prepared instructions and skill files, and choose which approved memory to include. Save the version ID and digest with the result.

```ts
import { AcclimateClient } from '@acclimate/sdk';

const { ACCLIMATE_URL, ACCLIMATE_TOKEN, ACCLIMATE_SCOPE, ACCLIMATE_CONNECTION } = process.env;
if (!ACCLIMATE_URL || !ACCLIMATE_TOKEN || !ACCLIMATE_SCOPE || !ACCLIMATE_CONNECTION) {
  throw new Error('Set ACCLIMATE_URL, ACCLIMATE_TOKEN, ACCLIMATE_SCOPE, and ACCLIMATE_CONNECTION');
}
const client = new AcclimateClient({
  baseUrl: ACCLIMATE_URL,
  token: ACCLIMATE_TOKEN,
  scope: ACCLIMATE_SCOPE,
  connectionId: ACCLIMATE_CONNECTION,
});
const prepared = await client.prepare({ workspaceId, bundleId, channel: 'stable' });
```

The snippet uses app-provided IDs and environment values. For a job that runs to completion in this call, await its work and result retention in a `try` block and await `prepared.cleanup()` in `finally`. For background work, keep the files available until the actual job stops. The [Python SDK recipe](/docs/reference/python-sdk) uses a context manager for a job that completes before the block exits.

## Report job starts

If your connection tracks deliveries, give the app a separate receipt credential in `ACCLIMATE_RECEIPT_TOKEN` and the connection ID in `ACCLIMATE_CONNECTION`. Build a reporter with its own client, using the receipt token and connection ID your app reads from those variables, and pass it to `prepare` as `reporter`. The console's **App setup** recipe shows the same pattern for Python with `DeliveryReporter`.

```ts
import { AcclimateClient, createReceiptReporter } from '@acclimate/sdk';

const reporter = createReceiptReporter({
  workspaceId,
  connectionId,
  client: new AcclimateClient({
    baseUrl: ACCLIMATE_URL,
    token: receiptToken,
    scope: ACCLIMATE_SCOPE + ':receipts',
    timeoutMs: 1000,
    retries: 0,
  }),
});
const prepared = await client.prepare({ workspaceId, bundleId, channel: 'stable', reporter });
```

At the job's real start event, call `prepared.reportStarted()` (Python `prepared.report_started()`) and retain the returned receipt with its job ID. It returns `null` when reporting is unavailable. For the TypeScript reporter, `await reporter.flush()` and call `reporter.close()` when the job ends. For Python, call `wait(timeout)` and then `close(timeout)`.

## Choose a native integration

Native plugins take a verified version, or the result of `client.prepare()` so its start receipt survives, and prepare a fresh private directory for the agent SDK. Each mapping accepts at most one instruction. A skill lives under `skills/<name>/` and needs a `SKILL.md` whose frontmatter has exactly one `name` matching the directory and one `description`. Other frontmatter keys such as `license` or `allowed-tools`, and folded `description: >` values, are kept as written. Supporting files of any text type, such as `scripts/check.py` or `config.json`, stay beside the skill. Each compatibility error names its rule, for example `[skill_metadata]`.

To add a harness without a plugin, use `prepareNativeFiles` from `@acclimate/sdk/native-files` with your agent's layout:

```ts
import { prepareNativeFiles } from '@acclimate/sdk/native-files';

const prepared = await prepareNativeFiles(verifiedVersion, {
  mapping: { instructionPath: 'AGENTS.md', skillRoot: '.agents/skills', memoryRoot: '.acclimate/memory' },
  prefix: 'my-agent-',
  target: 'codex',
});
```

| Agent SDK | Prepared layout |
| --- | --- |
| [Codex](/docs/integrations/codex) | `AGENTS.md` and `.agents/skills/` |
| [Claude Agent SDK](/docs/integrations/claude-agent-sdk) | `CLAUDE.md` and `.claude/skills/` |
| [Pi](/docs/integrations/pi) | `AGENTS.md`, `.agents/skills/`, and resource descriptors |
| [Cursor](/docs/integrations/cursor) | `AGENTS.md` and `.cursor/skills/` |

## Prepare an existing repository

The native repository starter provides an offline replay harness. Extract it from the release and run `node smoke.mjs` in its directory to check preparation before installing a provider SDK. Use the [native repository starter README](https://github.com/anveld-dev/acclimate/tree/main/examples/native-repository#readme) for configuration and private job recovery.
