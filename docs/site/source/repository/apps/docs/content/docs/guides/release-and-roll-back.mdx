title: Release and roll back

A release points a channel such as `stable` at an immutable version and records the reason. This guide changes a channel by hand.

To undo a version the learning loop adopted, use **Roll back** on its round instead, which also blocks it from adoption. See [Pause, stop and roll back](/docs/guides/learning-loop#pause-stop-and-roll-back).

## Release a version

Creating a bundle in the console makes its first release. To release a new version, use the SDK or the [HTTP API](/docs/reference/http-api) with a machine token that has read, write and promote.

1. Read the channel's current revision and version (read).
2. Upload the new files as a version (write).
3. Release that version to the channel with the revision you read and a reason in `unevaluatedReason` (promote).

<Tabs items={['TypeScript', 'Python']}>
<Tab value="TypeScript">

```ts
import { randomUUID } from 'node:crypto';

const current = await client.inspectSource(workspaceId, bundleId, 'stable');
if (!current) throw new Error('The channel has no release yet');

const version = await client.createVersion(
  workspaceId,
  bundleId,
  { parentVersionId: current.version.id, payload },
  randomUUID(),
);

const release = await client.createRelease(
  workspaceId,
  bundleId,
  'stable',
  {
    versionId: version.id,
    expectedRevision: current.revision,
    unevaluatedReason: 'Ship updated instructions',
  },
  randomUUID(),
);
```

</Tab>
<Tab value="Python">

```python
import uuid

current = client.inspect_source(workspace_id, bundle_id, "stable")
if current is None:
    raise RuntimeError("The channel has no release yet")

version = client.create_version(
    workspace_id,
    bundle_id,
    {"parentVersionId": current["version"]["id"], "payload": payload},
    str(uuid.uuid4()),
)

release = client.create_release(
    workspace_id,
    bundle_id,
    "stable",
    {
        "versionId": version["id"],
        "expectedRevision": current["revision"],
        "unevaluatedReason": "Ship updated instructions",
    },
    str(uuid.uuid4()),
)
```

</Tab>
</Tabs>

`client` is an `AcclimateClient`, and `payload` has the shape shown in [Publish a bundle from a file](#publish-a-bundle-from-a-file). The last argument of each write is its idempotency key. Reuse a key only to retry the same request ([Retry a write](/docs/reference/http-api#retry-a-write)).

If the channel moved after you read it, the release is refused with `revision_conflict`. Read the revision again and decide whether to release.

New jobs resolve to the released version. Prepared jobs keep theirs.

## Roll back

Rolling back creates a new release that points the channel at an earlier version. No history is removed.

1. Open the bundle's **Releases** tab.
2. Select the earlier release and inspect its files.
3. Choose **Restore**, enter a reason and confirm.

From a script, release the earlier version's ID with `createRelease` (`create_release` in Python).

If the console shows **Restore needs confirmation**, the restore may still have gone through. Do not submit a new one yet:

1. Choose **Check result**.
2. If it is still unknown, choose **Retry exact restore** to resend the stored request, or **Close unresolved restore**.
3. Start a new restore only after the operation is confirmed or closed.

## Publish a bundle from a file

To create a bundle from a script instead of the console's **Bundles** page, publish a payload file: a JSON object that holds the bundle's files. A file's `kind` is `instruction`, `skill` or `memory`.

```json title="payload.json"
{
  "schemaVersion": 1,
  "files": [
    {
      "path": "instructions.md",
      "kind": "instruction",
      "text": "You are a support agent for a small software company.\n\nAnswer in two short paragraphs. Ask one clarifying question when the request is ambiguous.\n"
    }
  ]
}
```

From a source checkout, with `ACCLIMATE_URL`, `ACCLIMATE_WORKSPACE` and `ACCLIMATE_TOKEN` set, run:

```sh
ACCLIMATE_SCOPE=examples npm run example:publish -- payload.json "Example agent" "First version"
```

The arguments are the payload file, the bundle's name and the reason for its first release. The command creates the bundle, its first version and its first release on `stable`, then prints their IDs. Set `ACCLIMATE_CHANNEL` for another channel. The machine token needs write and promote ([Rights](/docs/reference/credentials#rights)).
